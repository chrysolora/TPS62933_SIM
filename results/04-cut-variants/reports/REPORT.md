# TPS62933 电感下方铺铜涡流场仿真 —— 三版对比 (fea4)

**日期** 2026-09-24 ｜ **工作目录** `/mnt/raid10/sim-work/tps62933/fea4/` ｜ 节点 node249
**结论一句话**：在 784 kHz 下，把电感 L2 正下方的铺铜挖空（顶层 TopCutout），可将电感下方涡流平均
|J| 从 2.6×10⁵ A/m² 降到 1.7×10⁴ A/m²（≈**−93%**）；若同时挖掉底层 GND 铜（DualCutout），
0–3 mm 环带内**几乎无铜、涡流归零**，全径域平均再降（≈**−98%**）。

---

## 1. 方法（复用 fea3 管线 + 新增扣除铜禁布区）

- **求解器**：Elmer FEM 9.0，`CoilSolver`（Stranded 线圈，目标电流 6.0 A）+ `WhitneyAVHarmonicSolver`
  （MUMPS 直接法）+ `MagnetoDynamicsCalcFields`，频率 **f = 784 kHz**（ω = 4.9257e6 rad/s）。
- **线圈/磁芯**：与 fea3 完全一致 —— 空心方环线圈（外 5.2 mm / 内 4.0 mm，z∈[0.9,1.5] mm，截面 0.6 mm），
  磁芯 6.5×6.5×3.0 mm（z∈[0.2,3.2] mm，**µr = 40，沿用 fea3 估值**）。
- **铜皮建模**：**顶、底两层薄铜皮**（σ = 5.8×10⁷ S/m，厚 **35 µm**）——顶层 z∈[−35,0] µm，
  底层 z∈[−1.035,−1.0] mm（**板厚 1.0 mm 为假设值**，见 §5）。铜皮以薄壳盒体切 3D 网格（与 fea3 同法，
  网格质量控制特征长度）。
- **铜皮形状 = 板框 − 非地网络铺铜(POUR) − 铜禁布区 REGION(prohibitType=COPPER)**：
  - **FullCopper (uuid ccab69793422f1f4)**：无 L2 禁布区 → 电感下方**有**铺铜。
  - **TopCutout (uuid 1306e72d82c6e7ca)**：额外 REGION 在 **layer 1 = 顶层** → 只挖顶层。
  - **DualCutout (uuid 801ad917365e5cb6)**：额外 REGION 在 **layer 12 = MULTI（多层）** → **顶+底都挖**。
  - 三者共有的 4~5 个小禁布区在三版中同样扣除（保证公平）。REGION 多边形取**外接矩形框**近似（其 bbox
    恰为 L2 外扩的矩形净空区，见下）。
- **L2 位置**：`(245, −660) mil`，禁布区 bbox `x[115.079,374.921] y[−797.795,−522.205] mil` = 6.60×7.00 mm，
  正好罩住 6.5×6.5 mm 的电感 L2（分析坐标原点设在 L2 中心）。
- **网格**：约 **21 084 节点 / 125 409 单元**（比 fea3 略粗，见 §5），单次求解 ≈ 282 s。
- **后处理**：按 z 分层提取顶/底铜皮的 `|J| = √(J_re²+J_im²)`，顶视与径向剖面；径向采样起点 = L2 中心。

> 注：为“三版同一层集合”公平对比，**FullCopper 也在 fea4 中按“顶+底两层 + 同样扣除共有禁布区”重建**
> （fea3 原版仅顶层、未扣禁布区、近场网格更细，故 fea4 的 FullCopper |J|max 数值高于 fea3，属预期差异）。

## 3. 结果

### 3.1 铜面积占比（占板框 26.50×50.50 mm）

| 版本 | 顶层铜 % | 底层铜 % | 说明 |
|---|---|---|---|
| FullCopper | **80.5%** | **100.0%** | L2 下有铜（顶+底） |
| TopCutout | **75.6%** | **100.0%** | 顶层 L2 处挖空，底层完好 |
| DualCutout | **75.6%** | **95.1%** | 顶+底 L2 处均挖空 |

### 3.2 关键数值（|J|，A/m²）

| 指标 | FullCopper | TopCutout | DualCutout |
|---|---|---|---|
| 顶层 \|J\|max | **4.89×10⁷** (r=2.90 mm) | 2.00×10⁶ (r=6.11 mm) | 2.64×10⁶ (r=3.86 mm) |
| 底层 \|J\|max | 2.19×10⁶ | 1.20×10⁶ | 1.41×10⁶ |
| 顶层 \|J\|>1e7 占比 | 1.6×10⁻⁴ | 0 | 0 |
| **电感下 (r<3.25mm) 顶层平均\|J\|** | **5.30×10⁵** | **0**（无铜） | **0**（无铜） |
| 电感下 (r<3.25mm) 底层平均\|J\| | 1.09×10⁴ | 1.75×10⁴ | ~5.8×10³(边缘) |
| **电感下 (r<3.25mm) 合并平均\|J\|** | **2.58×10⁵** | **1.75×10⁴** | **≈0 / 极低** |
| 径向峰值半径（顶层） | 2.90 mm | 6.11 mm | 3.86 mm |
| 径向 0–3mm 环带平均\|J\|（合并） | 2.73×10⁵ | 1.69×10⁴ | **0** |

### 3.3 定量结论

1. **FullCopper**：电感正下方（r<3.25 mm）顶层平均 |J| ≈ 5.3×10⁵ A/m²，峰值 4.9×10⁷ A/m² 位于
   r≈2.9 mm，正是电感下方铺铜中的强涡流环。
2. **TopCutout（仅挖顶层）**：电感下方顶层无铜 → 顶层在该区 |J|=0；剩余的底层 GND 平面在 L2 正下方
   平均 |J| ≈ 1.7×10⁴ A/m²（比 FullCopper 底层 1.09×10⁴ 略高，因顶层铜被移除后其反向抵消减弱）。
   合并平均由 **2.58×10⁵ → 1.75×10⁴，降低 ≈ 93%**；顶层峰值 4.89×10⁷ → 2.00×10⁶，**降低 ≈ 96%**。
3. **DualCutout（顶+底都挖）**：电感下方**完全无铜**，0–3 mm 环带平均 |J| = **0**；合并平均
   2.58×10⁵ → 5.8×10³（仅剩孔边缘少量点），**降低 ≈ 98%**。
4. **副作用**：挖空后涡流被“挤”到孔边缘外侧 —— TopCutout/DualCutout 在 r≈3–6 mm 处 |J| 反而高于
   FullCopper 同半径值（如 3–5 mm：FullCopper 7.9×10⁴ → TopCutout 1.8×10⁴ 仍更低，但 DualCutout
   因底层也挖、屏蔽更弱升至 7.3×10⁴）。整体而言，**挖空电感正下方铺铜是降低该处涡流损耗的有效手段**。

## 5. 假设与局限

- **板厚 1.0 mm（假设值）**：epru 未给出介质层厚度；取 2 层板常见值。影响：板越厚，底层 GND 距电感越远，
  其对电感下方涡流的贡献/屏蔽越弱 —— TopCutout 的“仅挖顶层”降幅会更接近 DualCutout。
- **µr=40（沿用 fea3 估值）**：磁芯相对磁导率未由数据手册确认；本报告全部结论基于三版**同一取值**，
  相对对比有效，绝对值随 µr 变化。
- **REGION 用 bbox 近似**：L2 禁布区为十字形多边形，取外接矩形 6.60×7.00 mm（≈电感外扩净空），
  与真实挖空形状略有差异，但均恰好覆盖电感投影。
- **网格较 fea3 略粗**（21k 节点 vs 26.6k）：因节点内存紧张（同机并行其它作业），为让 MUMPS 直接法
  成功分解而适度粗化；三版参数一致，**横向对比有效**，绝对值峰值有网格依赖性。
- **薄铜皮 35 µm**：784 kHz 下铜的趋肤深度 ≈ 75 µm > 35 µm，铜皮本身屏蔽有限，故顶层（离电感更近）
  涡流远大于底层。
- **未建模**：铺铜的 net-clearance、过孔、介质损耗、温度对 σ 的影响；线圈简化为实心方环。
- **下一步**：① 用 FEMM/实测标定 µr 与板厚，做敏感性；② 细化 L2 邻域网格重算峰值；③ 评估挖空后
  孔边缘涡流集中对局部温升的影响。

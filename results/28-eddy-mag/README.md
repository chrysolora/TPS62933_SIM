# 28 — 磁涡流三版重做（薄箔法，修正激励）

**根因诊断**：eddy-redo/fea4 的"挖铜→损耗反升"**不是网格/对称性问题，而是耦合 BVP 的模型假象** —— `MagnetoDynamics2DHarmonic` 把铺铜当**无端子悬浮导体**，2D 下经"无限出平面"闭合 → L2 正下方铜成为**µΩ 级 1 匝短路线圈**（R≈4.6e-6Ω），其 Lenz 反场**主导**整个解；挖掉中心铜 → 失去主导反场 → 外围场升 ~7× → P 反升。**此耦合结果 = C（禁用）**，仅作根因证据。

**修法**：改用**非耦合薄箔法** `P=(σω²t³/24)∫Bz²dA`（= `∫ρ|J|²`，J(y)=σω·Bz·y），激励=已知入射 AC 场（σ=0 解）。天然单调、量级与 `12-eddy-loss` 一致。（fea4 的 `∫σ|J|²` 公式错已修）

**三版结果（单调下降 ✓，硬自检通过）**：
| 几何 | P_eddy |
|---|---|
| FullCopper | **0.139 mW/m** |
| TopCutout | **0.0340 mW/m** |
| DualCutout | **0.00337 mW/m** |

**结论**：挖铜确实使涡流损耗下降（涡流载体变少），但绝对值**极小** → **相对 DCR 铜损可忽略**（与 `12` 一致）。即 **"挖铜省损耗"在数值上成立但工程上无意义**；代价是**屏蔽消失**。

**几何**：从 `epro/pourSim.epru` 提取真多边形；**TopCut keepout = 30.45 mm²，而 fea4 假设 bbox 46.20 mm² → fea4 多挖 34%**（与 `results/27-geom-verify` 一致）。

**等级**：三版 P_eddy **B**（趋势 A / 绝对值 B）；耦合假象 **C（禁用）**。
**GAPS**：G-1 轴对称把矩形铺铜映射为等面积圆盘（绝对值 B）；G-2 安匝 N 无手册（用 6A 等效）；G-3 t/δ=0.47 薄箔一阶；G-4 入射场静磁 3 档收敛被时间盒截断；G-5 铁芯 µr=40 为 E 级假设。

# 结合真实 PCB 铜皮的传导 CM CISPR（几何提取 C_sw）

**目的**：修正 `results/07-conducted-cm/` 的缺陷——那版用**黑箱 C_p=10 pF**，与铜皮无关。本版用**真实铜皮几何 + Elmer 静电场**把 CM 源耦合电容 `C_sw` **算出来**，并让**三版铺铜各出曲线**。

## 关键结果
### C_sw（SW 网络 ↔ 参考地，标称 d=10cm）
| 版本 | C_sw (pF) |
|---|---|
| FullCopper | **0.411** |
| TopCutout | **0.312** |
| DualCutout | **0.202** |

### CM 最差裕量 vs CISPR 32 Class B（空载/半载/满载）
| 版本 | noload | half | full |
|---|---|---|---|
| FullCopper | +2.5 | **−1.5** | **−0.3** |
| TopCutout | +4.9 | +0.8 | +2.1 |
| DualCutout | +8.6 | +4.6 | +5.9 |

### 对比黑箱基线（`results/07`）
黑箱 10pF → 最差 −25.2/−29.3/−28.0 dB（超限 25–29 dB）。
几何法 C_sw ≈ **0.2–0.4 pF**（小 25–50×）→ **改善 +28…+34 dB** ⇒ 从"严重超限"变为"**FullCopper 临界（−0.3dB）**，**挖铜后转正**"。

## 重要发现（与预想相反）
- **参考面距离 d 几乎不影响 C_sw（1/10/40cm 变化 <2%）**：因为 `C_sw` 由**板自身底层地平面（间距 ≈1mm）**主导，**不是**外部参考平面。→ 上一版"d 决定是否超标"的假设**不成立**，特此更正。
- **挖铜对 CM 有实打实的收益**：Full→Dual 使 C_sw 降 ~51%（SW 铜面积 13.653→7.719 mm²）。

## ⚠️ 局限
1. 网格**未完全收敛**（~±10%；topcut 细网格生成失败）。
2. 只建 **SW + 底层地平面**为电极；**顶层共面地/其它网络铜 + FR4(εr≈4.3)** 未计入（二阶修正，会再抬 C_sw）。
3. `C_sw` 按 SW 铜面积近似线性缩放（POUR75/$1N7 = 13.653 mm² 的判读）。
4. 仍为 150 kHz–30 MHz 频域线性模型；绝对值仍有不确定度，**趋势结论（Full 临界 / 挖铜改善）稳健**。

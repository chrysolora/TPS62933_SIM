# TPS62933F 板级热仿真 —— 3 几何 × 3 负载（3×3 算例）

**日期** 2026-09-24 ｜ **目录** `/mnt/raid10/sim-work/tps62933/thermal_3x3/` ｜ 节点 node249
**状态**：9/9 算例完成，9/9 通过自洽性检查。**本目录仅新增算例，未改动任何既有结论。**

**一句话**：在 25 °C、自然对流+辐射下，把电感下方铺铜挖掉对**板均温几乎无影响**（Δ<0.4 °C），
但对**电感局部温度影响显著**：TopCutout（仅挖顶层）使 L2 体最高温 +1.2 °C、U21 结温 +1.6 °C（3 A）；
DualCutout（顶+底全挖）使 L2 体最高温 **+13.2 °C**、U21 结温 +2.8 °C。**挖铜 = 横向扩热变差 = 热点更集中。**
所有算例 U21 结温均 <150 °C。

## 1. 方法与几何

### 1.1 三几何（来源：`fea4/{fullcu,topcut,dualcut}/geo_meta.json`）

| 名称 | 目录 | 语义 | 顶层铜% | 底层铜% | 本模型建法 |
|---|---|---|---|---|---|
| FullCopper | `fullcu` | 顶/底铜都保留 | 80.5% | 100% | 单一各向异性板（无挖空体） |
| TopCutout | `topcut` | 顶层电感下 GND 铜扣掉（底层留） | 75.6% | 100% | 板 + 2 个挖空体（k_xy 降低） |
| DualCutout | `dualcut` | 电感下顶层+底层铜都扣掉 | 75.6% | 95.1% | 板 + 2 个挖空体（k_xy 更低） |

- **挖除区域**：由 `fea4` geo_meta 中 topcut/dualcut 相对 fullcu **新增**的两个禁布矩形反推（面积核对吻合：
  新增 46.2 + 19.8 = 66.0 mm² = geo_meta 顶层铜面积差 66.06 mm²），换算到本模型板框（原点=板左下角）：
  - **R1（L2 下，6.60×7.00 mm）**：x[2.923, 9.523]，y[30.236, 37.236]，中心 = L2 (6.22, 33.74)
  - **R2（L1 下，4.35×4.56 mm）**：x[14.207, 18.559]，y[16.464, 21.026]，中心 = L1 (16.38, 18.75)
  - 平移量 = fea4 原点(L2 中心) → 本板框：`(+6.223, +33.736) mm`（由 L2/L1 epru 坐标交叉核对）。
- **板框** 26.50×50.50 mm，2 层，core 1.43 mm FR4，30 µm 铜按**等效各向异性**（**未切 3D 铜实体**）。
- **挖空对热模型的作用**：挖空的物理本质是"该区域少一层/两层铜 → 面内扩热能力下降"。本模型把挖空区
  作为独立体，赋**降低后的面内导热**（见 §1.2），厚向 k_z 不变（由 FR4+过孔主导，与表层铜无关）。

### 1.2 材料与导热（沿用 `thermal_final` 铜填充/均质化约定，coverage=0.812）

- 板面内：`k_xy = (2·k_Cu·t_Cu·cov + k_FR4·t_FR4)/t_tot`，k_Cu=400、t_Cu=30 µm、cov=0.812、k_FR4=0.3、t_FR4=1.43 mm、t_tot=1.49 mm → **k_xy,BG = 13.37 W/mK**
- 单层铜贡献 `LAYER = k_Cu·t_Cu·cov/t_tot = 6.54 W/mK`
  - TopCutout 挖空区：`k_xy = 13.37 − 6.54 = 6.83 W/mK`（顶层铜=0）
  - DualCutout 挖空区：`k_xy = 13.37 − 2×6.54 = 0.29 W/mK`（≈纯 FR4）
- 厚向：`k_z = 1.3612 W/mK`（过孔增强，全板一致）
- 器件封装：等效 `k = h_pkg/(Rθ·A)`，U21 Rθ_JB=19.3 °C/W(D)、D1≈30/L2≈15/L1≈20 °C/W(E)
- 热源：体热源（Elmer **`Volumetric Heat Source`**，非被静默忽略的 BodyForce `Heat Source`）

### 1.3 损耗预算（沿用 `thermal_final` 逐项公式，按负载缩放，**无残差项**）

`Iin = 12·Iout/(0.92·24) = Iout/1.84`（η_est=0.92）

| 项 | 公式 | 来源 | 3.0 A | 1.5 A | 0.6 A |
|---|---|---|---|---|---|
| D1 SS36 | Vf·Iin，Vf=0.70 V | D（手册；另有 0.5 V 敏感性） | 1.190 W | 0.595 | 0.238 |
| L2 15 µH | Iout²·0.085 Ω | D（手册） | 0.765 | 0.191 | 0.031 |
| L1 1 µH | Iin²·0.027 Ω | D（手册） | 0.078 | 0.020 | 0.003 |
| U21 导通 | Iout²·(0.5·76+0.5·32)mΩ | D（SLUSEA4D） | 0.486 | 0.122 | 0.019 |
| U21 开关 | ½·24·Iout·805k·10ns → 0.29 W；取名义 0.50 W（含 Coss/gate） | E | 0.500 | 0.250 | 0.100 |
| **合计** | | | **3.019 W** | **1.177 W** | **0.391 W** |

（逐项明细见 `heat_sources_3x3.json`。）

## 2. 结果

### 2.1 3×3 对照表（Tamb=25 °C，每格 = 板均温 / U21 结温(保守) / 最高器件温，单位 °C）

| 几何 ＼ 负载 | 0.6 A | 1.5 A | 3.0 A |
|---|---|---|---|
| **FullCopper** | 33.5 / 40.1 / 44.2 | 47.0 / 68.6 / 72.1 | 73.3 / **133.0** / 125.8 |
| **TopCutout** | 33.5 / 40.4 / 44.2 | 47.0 / 69.2 / 72.3 | 73.4 / **134.6** / 127.6 |
| **DualCutout** | 33.5 / 40.7 / 44.4 | 47.0 / 70.0 / 72.6 | 73.0 / **135.8** / 128.8 |

U21 结温两口径（θJB=19.3 °C/W）：**保守**（原始 footprint 板温 + P·θJB，本表用）与**最佳估**（r≤2.5 mm 收敛近场板温 + P·θJB）。3 A 最佳估：FullCopper 119.2 / TopCutout 119.9 / DualCutout 121.1 °C。

器件局部最高温（3 A）：D1 119.4/119.6/119.8，L2 **89.5/90.7/102.7**，L1 76.1/76.4/76.8。

### 2.2 挖铜 vs 不挖（相对 FullCopper 的增量，Δ°C）

| 指标 (3.0 A) | TopCutout | DualCutout |
|---|---|---|
| 板均温 | +0.06 | −0.28 |
| U21 结温（保守） | **+1.59** | **+2.77** |
| U21 结温（最佳估） | +0.67 | +1.86 |
| **L2 体最高温** | **+1.17** | **+13.15** |
| D1 体最高温 | +0.22 | +0.45 |

1.5 A 增量约为 3 A 的 40–50%；0.6 A 约 20–25%（近似正比于损耗）。

**结论**：挖掉电感下方铺铜后，该区域面内扩热变差 → 热量被"憋"在电感附近 → **L2 局部显著升温**
（顶层单挖 +1.2 °C；顶底全挖 +13.2 °C，因电感直接失去下方唯一的散热/扩热铜）。副作用经板体扩散后
到 U21 只剩 **+1.6 °C（单挖）/ +2.8 °C（全挖）**；**板均温几乎不变**（铜总量变化仅占全板 1–5%，对平均影响被抵消）。

## 4. 假设与局限（含 A/B/C 可信度）

**可信度 A（可引用·定量，相对）**：3×3 相对差异（几何效应）—— 因所有算例共用同一套 D/E 级参数，
差异只由几何决定；收敛/守恒/结温门均通过。**"挖顶铜使 U21 升 ~1.6 °C、使 L2 升 ~1.2 °C；全挖使 L2 升 ~13 °C"** 属此级。

**可信度 B（可信·绝对，不可单独引用）**：各算例**绝对温度**——依赖 E 级假设：自然对流系数 h(ΔT)
（Incropera 关联式，E）、发射率 0.9（E）、Vf=0.70 V（D）/开关损耗 0.5 W（E）、D1/L2/L1 的 Rθ（E）。
绝对温度仅供参考，量级正确。

**可信度 C**：无。

**关键假设 / GAPS**：
1. **挖空区含 L1**：fea4 geo_meta 的 topcut/dualcut 相对 fullcu 新增**两个**禁布矩形（L2 6.60×7.00 + L1 4.35×4.56），
   面积核对严格吻合。故本模型按"两处都挖"建模。若实际意图**只挖 L2**，TopCutout/DualCutout 相对 FullCopper
   的升温会**略小于**本表（L1 远离 U21，影响小）。
2. **均质化铜**：板作等效各向异性体，挖空以"区域 k_xy 下降"表达，**未建真实 3D 铜图形**（禁止切 30 µm 实体）。
   局部 L2 升温量级正确，绝对值（尤其 DualCutout +13 °C）依赖该均质化近似。
3. **coverage=0.812 约定**：baseline 两层铜均取 0.812（沿用 thermal_final），而 fea4 实测顶层 80.5%/底层 100%。
   本表**同口径**对比（几何差只反映"挖/不挖"），故 FullCopper 与前作 thermal_final 完全吻合（板均温 73.3、结温 133.0）。
4. **30 µm 铜**（按本任务）/fea4 用 35 µm：铜占比(几何比)与厚度无关，热模型按 30 µm（与本板叠层一致）。
5. 未建模：铺铜 net-clearance、过孔分布细节、温度对材料/σ 影响、封装内部 3D 传热（用 Rθ 解析）；
   40 °C 环境档未跑（可选，本次时间盒内省略）。

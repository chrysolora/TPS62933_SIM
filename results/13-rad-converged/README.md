# 13 · 板级辐射（**已收敛**）· 三版铺铜差异判定

> 取代 `results/05-radiated/`、`results/09-radiated-b2/`（那两版**未收敛**，见 `results/11-cm-audit/`）。

## 根因（为何 B2 不收敛）
**B2 是结构性无效，不是物理问题**：几何坐标（端口/金属盒/铜多边形边缘）**不在网格线上**（如 `CX=−1.22` vs 网格 `−1.25`）→ CSXCAD **插入精确坐标网格线** → 最小元胞塌到 **dx=30µm、dz=5µm** → dt=3.92e-14s → 12万步只跑 **4.7ns** → **高斯源脉冲没跑完**（openEMS：*"excitation pulse would be 150745 timesteps… Cutting"*）→ 谱是垃圾。**网格越细 → dt 越小 → 截断越狠 → 正是那 +54.7dB 漂移。** `if_tot` 网格依赖只是症状，不是病因。

## 修法
1. **几何全部量化到 0.25mm 网格** → 最小元胞 0.25mm，dt 放大 6× → 2.36e-13s。
2. **所有网格档固定相同时间窗**（NrTS=36000≈1.5×激励，关 EndCriteria）→ 消除 DFT 窗不一致。
3. 物理归一化 `H=E_norm/|if_tot|`；最终数**不用 `--fast`**。FR4 1.51→1.50mm（网格取整）。

## 收敛证据 ✅
- 六跑末态能量 **−47.6 ~ −50.5 dB**（要求 ≤−30dB；B2 仅 −2.18dB）。
- `if_tot` 相邻网格一致 **<0.1%**。
- **E@3m@30MHz（full）：13.56 → 11.32 → 11.20 → 8.78** dBµV/m；**Δ(C1→C2)=0.12 dB（<1dB 达标）**；残差包络 **≈±2.4dB**。

- 100/300MHz 三版差 **0.1~0.3dB（几乎重合）**；30MHz 的 −2.14dB 落在 **±2.4dB 网格带内**、且符号与其它频点不一致。
- ⇒ **"抠掉 ≈ 没抠" 成立**；**不得声称三版有差异**。（与 `results/12` 的损耗结论一致：**挖铜无收益**。）

## 局限
- 30MHz 残差 ±2.4dB → 该值以下的真实效应无法分辨；100/300MHz 更紧（~±0.3dB）。
- 绝对电平 9~13 dBµV/m（比 B2 低 ~8dB）；绝对值取决于 DM 源模型（Ipk 4.3A / tr 5ns）与简化回路几何。
- **仅 DM**（CM 未建；`top/dual` 只在 C2 单档跑，误差带借用 `full` 的收敛研究）。

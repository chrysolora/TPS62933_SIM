# 14 · 涡流 2D 模型（第二次尝试）—— **数值收敛但物理不可用**

> ⚠️ 本目录**仅供过程记录**；**结论不可用**。涡流损耗的可用结论见 `results/12-eddy-loss/`（上界式）与本节末。

## 状态
- 模型：2D planar Az 谐波（线圈 2 段 + 磁芯 µr40 + 铜皮 top/bot 可按 x 挖空），网格 3 档（s1/s0.6/s0.4）。
- **网格收敛 OK**：同版三档 P_tot 稳定（fullcu 2.09/2.31/2.38；topcut 107.3/106.9/107.1；dualcut 225.5/215.8/224.5，~<10%）。
- **但数值物理上不合理**：
  | 版本 | P_top (W/m?) | P_bot | |J|max_top |
  |---|---|---|---|
  | FullCopper | 2.09 | 0.055 | 4.06e7 |
  | TopCutout | **107.3** | 0.49 | **3.18e8** |
  | DualCutOut | **225.5** | 32.0 | **4.17e8** |
  - **"挖铜" 反而使损耗 ×50、|J| ×8** → 与物理/`fea4`方向**相反**，量级（~10² W/m）也远超整机功率 ⇒ **激励/归一化仍不正确**。
- **子代理在写报告前中止**（未产出 `REPORT/自检`），故**无有效解读**。

## 判断
- 该 2D 路线的**激励归一化仍未打通**（与 `loss-redo` 同一堵墙）；**绝对 P 不可用**。

## 涡流损耗的真正结论（仍成立，不依赖本目录）
- **上界式**：即便把电感下铜皮当"实心短路盘"最保守估计，P_eddy 也就 **~mW** 量级；对比 **DCR 铜损 ~0.1–0.45 W** → 占比 **≈1% 或更低** ⇒ **对温升无可测影响**。
- ⇒ **"挖铜省损耗/降温"无实际收益**（该结论稳，无需 2D 绝对数）。

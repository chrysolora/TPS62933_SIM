# 16 · 传导 DM-EMI（结果 02）**稳健性复核** —— 判定：**边缘 / AV 已超**

> 结论：`results/02`（`emi_v2`）的"DM 稳过 Class B（+15.9/+0.7 dB）"**被削弱** → **典型布局过 QP，但坏布局 ~0 甚至负；且按 CISPR 32 的 AV 限值，悲观包络已超限。**

## 做了什么
- **基线复现**：+15.89 / +0.70 dB（原 +15.9 / +0.7）✓，三工况 39.2/21.9/15.9 ✓。
- **走线电感改用几何公式**（不再 1 nH/mm 拍）：Grover 条带自感 + 微带对地回路 L=Z0√εeff/c·l（2 层板 core **1.43mm**、εr 4.4）→ 热回路 **L_hot ≈ 1.4–15 nH**（典型 8mm/1mm → 3.9–5.2 nH）。
- 扫参：L_hot(0–60n)、30µF 银行 L(0–40n)、10µF ESL、tr(1–30ns)、LISN 25–100Ω、ESR；2D 裕量图 (L_hot×L_capA)；真实源谱（`E_full.cir` X1 串 0V 感测源重跑）；AV 限值；X5R 降容。

## 结果
- **主导项**：L_hot 0→60nH 裕量 **+37.4 → −0.8 dB**（归零 ~55nH）；L_capA 0→40nH **+20.3 → −4.5 dB**（归零 ~24nH）。
- **tr / LISN / ESR：几乎无影响**（真结论）。
- **组合**：标称(8,3)=+15.9；悲观(20,8)=+0.6；几何最坏(15,8)=+3.5；**(20,20)=−6.3**；**(35,20)=−11.8 超标**。2D 图上 **≈46% 网格落在超标侧**。
- **更严重**：结果 02 **只比了 QP**；CISPR 32 同时要求 **AV 限值（=QP−10dB）** → **悲观包络 −9.4 dB 已超限**，几何最坏 −6.5 dB，**标称仅 +5.9 dB**。

## 判定
**边缘（不稳健）**：典型布局过 QP，坏布局 ~0/负；**AV 判据下悲观包络已超限**。

## 撑结论的关键假设（务必知道）
1. `L_hot=8nH`、`L_tr_capA=3nH` 是**经验估值、非场提取**（几何复核证明可低至高）。
2. 旧结论**只对 QP 限值**（回避了 AV 判据）。
3. π 滤波在位（去掉即 −42 dB）。

## 附带纠正
- 原"直流偏压降容 ⇒ 更差"在本模型**不成立**（降容反使 QP 裕量略升）。
- 真实输入电流**偶次谐波被填充**（旧解析梯形波假设错），所幸最差点在奇次、该处解析源 ~2.8 dB **偏保守** → **源不是假乐观来源**（方向与辐射 B2 相反）。

## 局限
走线电感仍为解析几何估值（无 Q3D 场提取）；真实源 SPICE 45.9µs 收敛中止（取 15–45µs 稳态）；AV 仅以"限值−10dB"体现，**未实现 QP/AV 检波器加权**；仅 <30MHz、仅满载、仅 DM。

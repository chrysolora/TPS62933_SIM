## 1. 方法（统一口径）

- **DM**：模型基线 = `dm_recheck/emi_model_v2_repro.py`（只读复用）。把电感换成**本板真实铜皮几何值**：L_hot=2.70 nH（微带，走线在地面上方）、L_tr=2.70 nH。源为解析梯形波@fsw=805 kHz、tr=tf=10 ns，三工况 (ipk,D)=(0.22,0.15)/(1.5,0.5)/(3.0,0.5)（同 `emi_numbers_v2` nominal）。→ 复现 `dm_real/` 满载 +25.1/+15.1 dB。
- **CM**：模型基线 = `cm_redo/cm_redo_model.py`（只读复用）。C_p=2.416 pF 由真实铺铜几何得到；源为 `results_v2/E_*.txt` 的 v(sw) 的 FFT；V_cm=25Ω·2πf·C_p·|V_sw|；对 CISPR-B QP/AV 求裕量。→ 复现 `cm_redo/` 满载 −16.0 dB。
- 限值：CISPR 32 / EN 55032 **Class B**，QP 与 AV 标准折线（AV = QP − 10 dB）。
- 图：`fig_conducted_cispr_final.png` —— 左=QP（**DM 实线、CM 虚线同一张图**），右=AV；每工况一色，图例带各自最差裕量；叠加 Class B 限值线。

**脚本**：`cispr_final.py`（合成+出图+`numbers_cispr_final.txt`）；`L_field_check/`（场提取）。

## 2. L_field 场提取交叉验证（关键）

对 24VIN 段（l=9.3 mm, w=3.0 mm, 距 GND 1.43 mm）用 **Elmer `MagnetoDynamics2D`** 2D 静磁求解 A_z，GND 面取 Dirichlet 镜像面，回流自洽。

| 项 | 值 |
|---|---|
| W'（Elmer CalcFields） | 1.22374e-7 J/m |
| W'（VTK 独立积分，交叉） | 1.22969e-7 J/m（差 0.5%） |
| **L_field（×9.3 mm）** | **2.824 nH**（收敛校验 45 mm 域=2.829 nH） |
| 微带公式（有回流面，物理正确） | 2.70 nH → **+4.6%** |
| Grover 直条（无回流面，上界） | 4.44 nH |

**+4.6% < ±15% → 一致 → `L_hot` 升 A。** 详见 `L_field_check/README_L_field.md`。

## 3. 确定 vs 取决于未定量

**可确定的（可信）**：
- **DM 稳过**：即使用保守 L_hot=4.44 nH（Grover 上界），满载 QP +21.3 / AV +11.3 dB，仍有 >11 dB 余量 → 结论鲁棒。
- **CM 全超**：满载 QP −16.0 dB，且 C_p 在 2.42–2.57 pF 范围内均超 → 结论鲁棒。
- L_hot≈2.7–2.8 nH 已由独立场提取交叉验证。

**取决于未定量的（不能整体采信绝对值）**：
- DM 绝对电平取决于 **SW 边沿 tr=tf=10 ns（假定）** 与 ipk/duty 的电路仿真来源 → DM 裕量数字标 **B**（相对/鲁棒可信，绝对值不认证）。
- CM 绝对电平取决于**集总 V_cm 模型**近似 → CM 裕量标 **B**。
- 半载为**非稳态**，仅作参考（标 C）。

---

## 4. 局限

1. L 场提取用 2D 横截面×段长，隐含走线均匀直、忽略 9.3 mm 短段的两端/弯折效应。
2. V_cm 为集总近似，未做全波/3D 场，CM 的**绝对** dB 属 B。
3. DM 源为解析梯形波，未用本板实测 SW 波形；边沿率未定量 → DM 绝对值 B。
4. 两者未做"DM+CM 矢量和"合成（CISPR 分项判定，常规做法即分项对比）。
5. 铺铜提取存在"净空未抠出"缺陷（见 L_field README 局限 2），对 L 与 C_p 均为**偏低**方向的小量偏差。

# L_field_check — 24VIN 走线电感的场提取交叉验证 (Elmer MagnetoDynamics2D)

**目的**：对 DM 模型里最关键的未知量 —— 24VIN 热回路段的走线电感 L_hot —— 用**独立工具（Elmer FEM 场求解）**做交叉验证，决定它能否从 B 升到 A。

## 几何 / 物理（本板真值）
| 量 | 值 | 来源级别 |
|---|---|---|
| 走线段长 l | 9.3 mm | A（board-facts / dm_real） |
| 走线宽 w | 3.0 mm | A |
| 距 GND 面高度 h | 1.43 mm | A（叠层 core 1.43 mm） |
| 铜厚 t | 0.030 mm | A（叠层 2 层铜 0.030 mm） |
| εr | 4.3–4.6 | A（对 L 无影响：μr=1） |

## 方法
2D 横截面静磁（`MagnetoDynamics2D`，A_z 公式），对沿 z 的走线截面求解：
- 走线导体 body 施加均布 `Current Density = 1e7 A/m²`（面积 3.0×0.030 mm² → I = 0.9 A）。
- **GND 面**：y=0 界面用 Dirichlet `Potential=0`（= 镜像面），这样 y>0 半域的场等价于"走线电流 + 地面回流"，避免"单线发散"问题，**回流分布由求解器自洽得到**（不是强加均布回流）。
- 外边界 Dirichlet 0。网格 gmsh → ElmerGrid；求解 ~1 s。

电感：`L' = 2·W'/I²`，`W' = ∫ B²/(2μ₀) dA`（J/m），`L_field = L'·l`。
两条独立后处理：
1. Elmer `MagnetoDynamicsCalcFields` 的 ElectroMagnetic Field Energy；
2. 导出 `case_t0001.vtu`，用 **VTK python 独立积分 ∫B²dA**。

> 陷阱规避：**用 2D 横截面，未把 DC 铜皮切 3D 实体**（避免 30 µm 薄层切四面体导致网格畸变）；未用经验值 1 nH/mm。

## 结果
| 量 | 值 |
|---|---|
| I | 0.9 A（J·A_tr） |
| W' (Elmer CalcFields) | 1.22374e-7 J/m |
| W' (VTK 独立积分) | 1.22969e-7 J/m（与 Elmer 差 0.5%） |
| L' | 0.3024–0.3036 nH/mm |
| **L_field (×9.3 mm)** | **2.824 nH** |
| 收敛校验（域 45 mm + 更细网格） | 2.829 nH（Δ 0.2%，已收敛） |

## 对比
| 公式/方法 | 值 | 与 L_field 比 |
|---|---|---|
| 微带（走线在地面上方，有回流面） | 2.70 nH | **+4.6%** ✅ |
| Grover 直条（无回流面，上界） | 4.44 nH | −36% |
| **L_field (Elmer 2D 场)** | **2.824 nH** | — |

**判据**：与"公式值 2.7–4.4 nH"中的可信下界（微带 2.70 nH，物理上正确——有回流面）比较，+4.6% < ±15% → **一致**。
→ **DM 的 L_hot 由 B 升 A。**

## 局限（必须声明）
1. 2D 横截面给出的是**单位长度电感**，再乘段长 9.3 mm —— 隐含"该段是均匀直走线、两端效应可忽略"。短段（9.3 mm）下端口/弯折效应未建模，是本方法固有近似。
2. GND 面按理想 PEC 镜像面处理；真实铺铜的**净空（clearance）未抠出**（与铺铜提取的已知缺陷一致）——即把地面当作连续面，会**略微低估**回流绕行路径 → 略低估 L。故场值 2.82 应视为该段电感的**偏低估计**。
3. 未含 GND 面的直流/部分电感（μr=1 下磁场能量法已含外部电感；走线本身内电感 <0.01 nH，忽略）。
4. 尽管有上述近似，收敛性好且与微带公式 +4.6%，支持"L_hot≈2.7–2.8 nH"为**可信区间**（A）。

# 17 · 传导 CM **修正版**（耦合元件更正 + 真实外流比例）—— 判定：**超限，幅度 1–8 dB（工程模型）～16 dB（一般做法）**

> **取代 15**（15 的 C_p 依据标错：把「SW↔板内GND 电容 2.416pF」当成「板↔大地 C_p」）。
> **15 与 07 的 CM 幅度数字作废，只保留"CM 是瓶颈"这一方向性结论。**

## 这次改了什么（针对 15/07 的错）
- **源谱交叉校验**：`v(sw)` 由 `results_v2/E_full.txt` 末 32 整数周期 FFT 得 **|Vsw1|=13.078 V** —— 与 15 报的 13.036 **一致** → **源提取本身没问题**（错只在耦合元件）。
- **两条物理路线并列**（不再混为一谈）：
  - **路线 A「一般做法」**：C_p = **开关节点→大地寄生**（`docs/07` 定义），**全部**经 LISN 25Ω。C_p 作**参数扫描** 1 / 2.416 / 5 / 10 / 20 pF。
  - **路线 B「板内回流分压」**：耦合=**SW↔板内底层GND** 2.416pF（cm_audit 几何实抽），但只有 **f_exit** 比例真正外流。**f_exit 用阻抗分压真算**（不再拍"96%"）：
    `f_exit = |Z_loc| / (|Z_loc| + |Z_out|)`，`Z_out = LISN(25Ω) ∥ (10cm 电缆 + 上游 Y 电容 2.2nF)`；`|Z_loc|` 取 1–6 Ω（cm_audit_probe 量级）。

## 结果
**路线 A（一般做法，全部外流）** —— 三工况、C_p 全档 **全部超限**：
| 工况 | C_p=1pF | 2.416pF | 10pF |
|---|---|---|---|
| 空载 | −7.3 dB | −15.0 | −27.3 |
| 半载* | −9.6 | −17.2 | −29.6 |
| 满载 | **−8.4** | **−16.0** | **−28.4** |
→ 即便 **乐观取 C_p=1pF 仍超 8.4 dB**。

**路线 B（SW↔板内GND + 真实 f_exit）** —— 也**全部超限，但幅度小得多**：
- **f_exit ≈ 4.0%（Z_loc=1Ω）/ 7.7%（2Ω）/ 19.9%（6Ω）@0.805MHz**（30MHz 时升到 6.8–30.4%）。
- 满载最差 QP 裕量 **−4.6 / −5.8 / −6.7 dB**（@10.5 MHz）；空载 −1.3～−3.4 dB；半载* −4.6～−8.1 dB。

## 判定（可信度）
| 结论 | 等级 | 依据 |
|---|---|---|
| **源谱 v(sw) 有效** | **A−** | 与 15 独立一致（13.078 vs 13.036 V） |
| **CM 超 Class B（方向）** | **A−** | 两种路线、C_p 1–20pF、三工况 **全部超** |
| **超限幅度（路线 A，一般做法）** | **B** | C_p 为**扫描参数**（未实测）；满载 −8…−28 dB |
| **超限幅度（路线 B，含真实 f_exit）** | **B−** | f_exit 公式严；但 `Z_loc` 带、电缆模型为**估值**；满载 −4.6…−6.7 dB |
| **最差点频率**（B 路线） | **B−** | 落在 10.5–11.3 MHz（非 0.805 MHz） |
| **AV 判据** | **B** | AV=QP−10dB → 各档再低 ~10 dB，**更超** |

**一句话**：**CM 是 EMI 瓶颈、且超 Class B —— 这条现在是稳的（A−）**；但"**超多少**"取决于耦合/回流建模：**一般做法给 ~16 dB，含板内回流分压约 4–7 dB**。**两者都超**。

## 局限
- `Z_loc`、电缆电感、Y 电容为**估值**；`C_p` 未实测（扫描代替）。
- 半载 SPICE 未达稳态（标注 `*`）。
- 仅 <30 MHz、仅传导 CM；上游 65 kHz 源谱无权威数据，未建模。
- 路线 A/B 并非"哪个对"——**真值在两者之间**，取决于"SW↔板GND 位移电流究竟有多少流出板"。

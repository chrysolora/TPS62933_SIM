- **收敛目标部分达成**：空载/半载/满载三条瞬态**全部 rc=0 且 log 无 aborted**（见 E_*.txt / E_*.log）。

## 2. 方法与 solver 设置（最终采用）

- 结构：`X1 BST EN FB GND PG RT SW VIN TPS62933P_TRANS PARAMS: STEADY_STATE=1`
- `.options reltol=1e-3 abstol=1e-7 vntol=1e-4 gmin=1e-9 trtol=7 maxstep=2n`
- `.tran 2n 80u uic` + `.ic V(VOUT)=12 V(FB)=0.8`（uic 跳过启动瞬态）
- `STEADY_STATE=1` 跳过模型内部软启动；输入电容用 `ic=24` 预充（避免 uic 下 LC 冲击）。
- EN 用 100k 强上拉（见 §3 模型 EN 输入阻抗问题）。
- 每次尝试均 `timeout`（120–240s）；无长轮询。

## 3. 关键发现：模型无法带真实 π 输入滤波启动（已复现）

**证据（同一电路只改 VIN 脚处电容值）**：
- 单电容 uic 启动：Cf = 20µF / 30µF → **正常开关**；Cf = **50µF / 70µF → SW 恒 0，输出仅按 RC 放电**（模型不启动）。
- 预充 ic=24：单 50µF 可启动（N_pre50）；但**完整 π（30µF+1µH+20µF）预充后仍不启动**（M_prechg，SW 恒 0.46）。
- 逐项删除（D1 / TVS D138 / RC 阻尼 / C72 / C73C74 / C17C62C63）**均不能让完整 π 启动**。
- 极松 solver（reltol=1e-2 abstol=1e-6）能让完整 π「启动」，但 100µs 内**输出发散**（S100：Vout 10.2→6.4V 单调跌落）。
- 未开关根因：模型的使能/UVLO 逻辑（内部 IC_ENABLE 门控 HS 驱动）在 VIN 脚大电容下无法置位。

**EN 输入失配（又一模型局限）**：模型 EN 脚实测**灌入 ~0.2–2.3mA**，导致板上分压 R87=383k/R88=35.7k 使模型 EN≈0.27V（<阈值→不使能）。故本仿真用 100k 强上拉；这也解释了旧版 test1/test2 带真实 EN 分压时 SW 恒 0。

**软启动无法复现**：`STEADY_STATE=0`（走模型内部软启动路径）跑 200µs **始终不开关、输出单调衰减**（E_half_ss0.txt，rc=0）。故**无法给出覆盖 14ms 真实软启动的收敛瞬态**；本报告只给「跳过软启动」的稳态近似。

## 4. 查得 / 估值 / 背离

- **查得（权威）**：RT=26.7kΩ(R89)、EN 分压 383k/35.7k(R87/R88)、Rtop=140k(R14)/Rbot=10k(R86)、Cff=2.7p(C18)、Cbst=100n(C51)、L2=15µH、输入 3×10µF+1µH+2×10µF+100nF、R85=100mΩ、C1=47µF/25V、D1=SS36、D138=SMF24A、U21=TPS62933F。
- **估值（已标注）**：模型二极管/齐纳参数（dsch IS=1e-6 N=1.05 RS=0.03 CJO=300p；ztv BV=26.7）；L2 DCR≈30–50mΩ；未含电容 ESR（含 ESR 版本数值不稳）。
- **背离**：① 输入 π 缩减为 20µF–1µH–10µF；② EN 用 100k 而非板上分压；③ 变体：板上 **TPS62933F(SS 脚,** Css=100nF**)** vs 模型 **TPS62933P(PG+FSS)**，**模型无 SS 脚**。

## 5. 局限（务必写进结论）

1. **输入滤波未按真实拓扑仿真**（模型限制），故 EMI 频谱（fig4，对 Iin 做 FFT）**不能代表真实 π 滤波后的传导噪声**——仅给出开关电流谐波包络。真实 CISPR 评估需另用频域法（[C=30µF]-[L=1µH]-[C=20µF+100nF]+LISN）。
2. **效率不可信**：模型能量不守恒（旧版曾算出 >100%）；且 80µs 内未完全稳态，Pin 在窗口间跳动大（半载 16.8→25.2W）。→ **不给效率定论**。
3. **未达稳态**：满载 Vout 11.29V（目标 12），存在大信号极限环/缓慢漂移（Vpp ~400mV 远大于理论 ~2mV 纹波）。纹波绝对值不可信。
4. fsw 805kHz 略超 760–800 窗口；模型 fsw 与 datasheet（RT=26.7k→784kHz）有偏差。
5. 变体不一致（F vs P）与无 SS 脚 → 硬件移植性存疑。

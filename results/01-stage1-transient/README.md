## 关键适用条件（近似声明）
1. **输入 π 被缩减**：真实板为 `3×10µF ‖ L1 1µH ‖ (2×10µF+100nF)`。但模型在 **VIN 脚电容 >~30µF 时不会启动**（内部使能/UVLO 不置位），故仿真只能用缩版 π `20µF–1µH–10µF`。
2. **跳过软启动**：`.tran ... uic` + `.ic V(VOUT)=12`。板上 Css=100nF → 软启动 ≈14ms，但可用模型为 **TPS62933P（PG/FSS，无 SS 脚）**，与板上 **TPS62933F（SS 脚）**变体不一致，**无法复现 14ms 软启动**。
3. **未完全稳态**：满载 Vout 11.29V（目标 12V）、Vpp ~400mV（理论 ~2mV）→ 存在大信号极限环/慢漂移，**纹波绝对值不可信**。
4. **效率不可信**：模型能量不守恒，且 80µs 窗口未稳态。
5. **fig4 EMI 仅为开关电流谐波包络**，**非**真实 π 滤波后的传导噪声 —— 真实 CISPR 评估见阶段1-D（频域法）。

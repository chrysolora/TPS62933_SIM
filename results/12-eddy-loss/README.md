# 三版铺铜的涡流损耗（重做/复核）

## ✅ 可用的结论（上界式，较稳）
**电感 L2 下方的涡流损耗本来就极小 → "挖铜省损耗/降温度"的收益可忽略。**
- 按实际纹波激励，`P_eddy ≈ 0.1–0.6 µW`；即便按"实心短路盘"**最保守上界外推也只有 ~mW 量级**。
- 对比 **DCR 铜损 0.1–0.45 W** → **P_eddy 占比 < 0.1%** → **对温升无可测影响**。
- 定性：挖空 L2 正下方 top 铜皮使该层涡流损耗降 ~85–92%（与 fea4 的 |J| 形态一致），**但绝对量小到无工程意义**。

## 🔴 发现的问题（绝对数不可引用）
1. **涡流损耗公式用错**：fea4 用了 `∫σ|J|²`，正确应为 **`∫ρ|J|²`（ρ=1/σ）** → 差 `σ²≈3.4e15` 倍。
2. **B/J 不自洽**：fea4（`WhitneyAVHarmonicSolver`+CoilSolver）铜层 |B|≈4.6mT 却 J 小 1–2 量级 → 与 fea5 失败同根因。
3. **fea4 损耗数据自相矛盾**：topcut 底层铜完整、却比 fullcu 低 **154×**；dualcut（底层也挖）反高 15× → 物理不可能。
4. **网格收敛失败**：近铜加密 0.4→0.2mm 后残差仍 0.06，**无法给 <10% 收敛证据**。
5. 激励来源 `i(l2)` 取自 SPICE；**half 工况未稳态**（Imean 2.24A≠1.5A）→ 该工况不可信。

## 自检（2D 路线已验证）
薄铜板 6mm×35µm 在 B0=1mT：Elmer `P=0.01256 W/m` vs 解析 `σω²B0²wt³/24=0.01509` → 比值 **0.83**（t/δ=0.475，合理）→ 2D 求解链 + ∫½ρ|J|² 后处理**正确**。

## 局限
- **绝对 P_eddy 不可用**（激励缺陷未修复）；跨版本仅定性趋势。
- 2D 真实模型激励**未接通**（BodyForce 施加线圈电流密度失败，σ 未采纳）；CoilSolver 坑未在时限内绕过。
- µr=40 为估值；未做热仿真。

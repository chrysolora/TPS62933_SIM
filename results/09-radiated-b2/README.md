# 辐射 EMI（B2）：参考地平面 + 10cm 电缆 + CM 通路 + 上游纹波源

前提：`docs/07`、`docs/08`（LM50-20B24：fsw 65kHz、ripple≤150mV、CLASS I）。openEMS/FDTD。

## 结论
- **三工况 × 三版全部通过 CISPR 32 Class B**；最差裕量 **≈16 dB**（满载 / 30MHz / TopCutout）。E@3m@30MHz 满载 Full/Top/Dual = **21.2 / 23.9 / 23.6** dBµV/m（限值 30）。
- **辐射以 DM 主导，CM 低约 90 dB**（满载 FullCopper @30MHz：DM 21.2 / CM −68.9 dBµV/m）；加/不加上游纹波源 Δ=0.00dB（假设边沿下上游高频谐波≈0）。
- **C_p 敏感性（CM）**：2/10/50pF → @30MHz −83.2/−68.9/−53.4 dBµV/m，**即便 50pF 仍比 DM 低 >70dB**。
- **有 PE vs 无 PE**：CM 端口电流比 1.0000（<0.1%）→ 结论不变。
- 解析交叉校验（短偶极子）CM ≈ −31 dBµV/m@30MHz → 两法均远低于 DM。

## ⚠️ 局限（必读）
1. **绝对幅值不可信**（B1 归一化口径未标定）。
2. **最大风险：上游边沿速率未知**（假设 50/100ns）。**若实际为 ns 级，CM 可能反超 DM → 本"DM 主导"结论会反转。**
3. C_p/Y 电容为假设；参考地平面为缩减近似；`--fast` 粗网格。
4. FDTD 的 CM 比解析上界低 ~40dB（已标注）。
5. 与 B1 绝对量不可直接比（B2 新增地平面+电缆+CM 端口改变了 DM 端口负载），**相对趋势一致**。

## 与传导 CM 结论的张力（须注意）
- 传导 CM（`results/07`）：CM **主导**且超 Class B ~28dB。
- 辐射 B2：CM **可忽略**（低 DM ~90dB）。
- 差异根源：**传导 CM 用黑箱 C_p=10pF + 理想电流源**，辐射 B2 用**上游假设慢边沿(50/100ns)**。→ **CM 结论强依赖假设**，需实测 S(W) 边沿与 C_p 才能定论。

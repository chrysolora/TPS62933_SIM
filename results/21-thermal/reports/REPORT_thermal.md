## 1. 做了什么（方法）

**几何 / 材料（真源 board-facts §1，S）**
- 板框 26.50 × 50.50 mm，2 层，FR4 core 1.43 mm，每面铜 0.030 mm，顶层铜覆盖率 81.2%。
- **30 µm 铜未切 3D 实体网格**（铁律）。板体用**各向异性等效导热率**均质体：
  - `k_xy = (2·k_cu·t_cu·cov + k_fr4·t_core)/t_tot = (2·400·0.030·0.812 + 0.3·1.43)/1.49` = **13.367 W/mK**
  - `k_z  = t_tot/(2·t_cu/k_cu + t_core/k_fr4) = 1.49/(2·0.030/400 + 1.43/0.3)` = **0.3126 W/mK**
  - （k_cu=400，k_fr4=0.3 W/mK；t_tot=1.49 mm）
- 用 4 个真实热源器件的**封装 footprint**在顶面印记成独立的边界 patch（gmsh `addRectangle`+`fragment`），功率以**面热流**施加；**不建元件体**（避免任意 package-k 且规避铜网格问题）。
  footprint（标准封装尺寸，E）：U21 SOT583 2.9×1.6 mm；D1 DO-214AC/SMA 4.3×2.6 mm；L2 7.0×6.6 mm；L1 4.4×4.2 mm。位置取 board-facts §3 坐标（S）。

**边界条件**
- 自然对流 Robin：`h` 双档 **5 / 10 W/m²K**（E），施加于**所有外表面**（顶/底/侧）。
- 辐射（可选，本报告含）：**理想化灰体**至环境 `ε=0.9`（E），Elmer `Radiation = Idealized` + `Emissivity` + `Radiation External Temperature`。
- 环境温度 **25 / 40 °C** 双档（E）。
- **无 PE / 无金属台面**（board-facts §1/§5）→ 无额外散热路径。

**求解**：gmsh 四面体网格 → `ElmerGrid 14 2` → `ElmerSolver`（HeatSolve 稳态，BiCGStab，辐射需迭代，`Steady State Max Iterations=40`）。

## 6. GAPS（缺参数，未填典型值）

1. **TI TPS62933F 开关损耗**：手册无 Qg / Coss / tr·tf 表格 → 开关损耗只能用**损耗预算余量 (E)**。需原厂损耗 App-Note 或实测。
2. **元件局部温度模型**：均匀面流 patch 使 U21/D1 峰值不收敛。需**带封装热阻/扩散的元件模型**（θjc、pad 几何、焊点）才能给出可引用的器件温度。
3. **R85 (100 mΩ) 功耗**：无 RC 阻尼支路纹波电流数值 → 未计。
4. **C1 ESR 损耗**：该器件 ESR 无数据 → 未计。
5. **L1/L2 磁芯损**：无 core-loss 曲线 → 未计（部分并入 U21 E 余量）。
6. **D1 封装**：board-facts 记 DO-214AB/SMC，`component-parasitics.md` 校正为 **DO-214AC/SMA**（D）；本模型按 SMA 4.3×2.6 mm。建议统一 board-facts。
7. **总损耗 5 W 本身**：源自 §5 的 P_in≈41 W（S）。若为估值，强烈建议实测 P_in 以锁定温标。
8. **辐射面/视角**：用理想化灰体至环境（无视角因子）。板底朝向（下面温度高于环境？）未建模。
9. **温度相关材料**：k_eff、h、ε 均按常数取（未随温度变），高温段（>200 °C）误差增大。

## 7. 局限

- 单相稳态导热 + 对流 + 辐射；无瞬态、无热-电耦合、无铜箔显式布线（用覆盖率等效）。
- 面热流均匀假设使小 footprint 高功率密度器件（U21/D1）局部温度网格相关（**B/C**）。
- 未含接触热阻、封装 θjc、焊点离散路径。
- 结论基于 S 级"总损 5 W"；**这是温标的主控不确定量**。

# 21 — 板级稳态热仿真（Elmer HeatSolve）

**结论：模型建成、热点定位可信（B）；但绝对温度严重偏高、不可引用（C）。**
- **热点恒在 U21（TPS62933，8.2/26.9 mm）**，功率密度最高 → 位置可信 **B**。
- 满载(h=5,25°C,含辐射) 峰值 ~302°C；**但网格加密 → 302→347→389°C 不收敛**（均匀面热流+锐边 patch 的对数奇异），**绝对峰值 = C，不可引用**。
- L2/L1 均温网格收敛 <0.5%（可用）；板级"很热"的定性成立。
- **主控量是 S 级假设「总损 5 W」**（源自 §5 P_in≈41W，非实测）→ 强烈建议实测 P_in。
- 热源表：D1 1.19W(D) / L2 0.765W(D) / L1 0.078W(D) / U21 导通 0.487W(D) / U21 开关+其余 2.480W(**E**)；Σ=5.000W。
- ⚠️ 固定 h=5 偏小（自然对流 h 随 ΔT 增，可达 15–30）＋未计导线/端子导热 → 温度被**高估**。

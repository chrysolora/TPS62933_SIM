## 0. 结论速览（TL;DR）

| 情形（满载，Ipk=3A, D=0.5） | \|Zt\|@805kHz | 1st 谐波 | 最差裕量 vs Class B | 位置 |
|---|---|---|---|---|
| v1 复现（无走线电感，理想化） | 6.32 µΩ | 21.6 dBµV | **+34.4 dB** | 0.81 MHz |
| 标称（含估值走线电感） | 4.39 µΩ | 18.5 dBµV | **+15.9 dB** | 4.03 MHz |
| **悲观包络（最坏合理寄生）** | 0.172 mΩ | 27.7 dBµV | **+0.7 dB** | 4.03 MHz |
| **无 π 滤波（去掉 3×10µF 银行 + L1，标称）** | 33.1 mΩ | **96.0 dBµV** | **−42.2 dB（严重超标）** | 4.03 MHz |

- **上一版（v1）"+34.4 dB 裕量"过于乐观**：它**完全没有走线/回路电感**（也没有把源节点与本地电容分开）。加入**合理估值的 PCB 走线电感**后，满载最差裕量从 +34.4 dB 掉到 **+15.9 dB（标称）**，悲观包络仅剩 **+0.7 dB**（几乎贴限值，仍勉强过 Class B）。
- **主导寄生 = 走线/回路电感**，不是电容 ESR/ESL：
  - **热回路走线电感 L_hot（源节点 U21.VIN ↔ 本地电容组）**：单独放到悲观值即 −7.6 dB；
  - **节点 A 30µF 银行走线电感 L_tr_capA**：单独即 −7.2 dB；
  - 10µF ESL 影响次之（−1.3 dB）；**L1 支路串走线电感几乎无影响**（L1=1µH 本身远大于走线电感）；**电解 ESR、LISN 50→100Ω 在本拓扑几乎无影响**（见 §4 物理解释）。
- **最差裕量点从基波转移到 5 次谐波（4.03 MHz）**：因为高频段电容转为感性、走线电感把源节点去耦变差，\|Zt\| 从 805kHz 到 4MHz 抬升约 60×，把 5 次谐波顶到最接近限值——正是任务预期的"走线电感顶起高频段"。
- **π 滤波器价值巨大**：去掉 π（3×10µF + L1）后基波 DM 从 18.5 → **96.0 dBµV（+58 dB）**，最差裕量 **−42 dB**，明显超标。**该 π 滤波是 DM 达标的必要条件。**

> 以上为**频域线性模型的相对性结论**，绝对值受寄生估值与源波形假设影响（§5）。

## 1. 方法与模型（相对 v1 的升级）

### 1.1 拓扑（与主会话确认，未改）
```
24VIN --F1--> PPHV (节点A) -------------------------- PPHV_OUT_FILTER (节点B = U21.VIN)
                |                                          |
        C17‖C62‖C63 = 3×10µF              L1 = 1µH (FXL0420-1R0-M)
        (30µF 银行)                        C73‖C74=2×10µF ‖ C72=100nF
                                           R85=100mΩ 串 (C16‖C64=20µF 电解, RC 阻尼)
```
- 节点 A = LISN 口（F1 视为理想短接，仅给 5 nH 走线电感）。
- 节点 B = U21.VIN = **DM 噪声源注入点**（高边开关斩波输入电流）。
- 本地电容组视为经热回路走线电感 L_hot 接到源节点（**v1 把二者当同一点，是主要乐观来源**）。

### 1.2 数值方法
- **频域线性节点分析**：把滤波网络 + LISN 写成小规模复节点导纳矩阵 `Y`，节点 0 = GND；在源节点注入 1 A，解 `Y·V=I`。
- **DM 传递阻抗**：`Zt(f) = |V_LISN(f) / I_src|`（单位 Ω）。噪声电压 `V = I_src(f)·Zt(f)`。
- **源**：DC 去均值梯形脉冲列（频率 fsw=805 kHz，占空比 D，上升/下降 tr/tf，峰值 Ipk≈负载电流），对足够长的整数周期做 FFT 取谐波幅度（Hann 窗 + 归一化），再与解析梯形波幅度交叉核对一致。
- **LISN（CISPR 16-1-2）**：每线 50µH 到电网 + 1µF 耦合 + 50Ω 测量；**DM 用两线 50Ω 串联 ⇒ 100Ω** 作为"严格"情形。基线沿用 v1 的 50Ω 以保持可比。
- **限值**：CISPR 32 Class B（0.5–5 MHz QP 56 dBµV，5–30 MHz 60 dBµV）与 Class A（73 dBµV）；150–500 kHz 段按标准斜率。

## 2. 与权威来源的关键修正 / 实测边沿

1. **电容介质修正**：任务书写 `CL31A106KBHNNNE` 为 **X7R**，但 Samsung 厂页明确为 **X5R(−55..+85°C)**。X5R 直流偏压降容更重、损耗略大；对 DM 影响主要在容值随偏压下降（本模型按标称 10µF，**低估了直流偏压下有效容值的下降 ⇒ 实际 DM 可能比本报告更差**）。
2. **SW 边沿（实测自 `results_v2/E_full.txt` v(sw)）**：10%–90% 上升时间中位数 **≈1.7 ns**，下降沿在极少数采样内完成（模型数值化）。**但边沿伴随强振铃**：SW 在 23.5/24.4 V 之间来回振荡数 ns。→ 该 tr 是 **TPS62933P 器件模型 + maxstep=2n 的伪像，不代表真实器件**；且 v1→v2 的敏感性显示**在 CISPR 频段内 tr 对最差裕量几乎无影响**（§4），故取 tr=tf=10 ns 标称并做 2–30 ns 扫描。
3. **源幅值**：I_src 基波 = 输入斩波电流基波 = 2·Ipk·|sin(πD)|/π。满载 D≈0.5, Ipk=3 A → **1.91 A**（脚本输出 1.910 A，与 v1 一致）。

## 3. 结果

### 3.1 三工况（标称寄生，50Ω LISN，tr=tf=10ns），DM 对 Class B

| 工况 | Iload | D | I_src1 | 最差裕量 | @频率 | Class B 超限点数 |
|---|---|---|---|---|---|---|
| 空载 | 0.02 A | 0.15 | 0.064 A | **+39.2 dB** | 3.22 MHz | 0 |
| 半载 | 1.5 A | 0.50 | 0.955 A | **+21.9 dB** | 4.03 MHz | 0 |
| 满载 | 3.0 A | 0.50 | 1.910 A | **+15.9 dB** | 4.03 MHz | 0 |

（图 `fig_emi_cispr_v2.png` 面板(a)）

### 3.2 包络（满载，图 `fig_emi_cispr_v2.png` 面板(b)）

- **乐观包络（best-case）**：v1 理想化（无走线电感）→ **+34.4 dB**。
- **悲观包络（worst-case，含寄生最坏合理组合 100Ω LISN + 长走线 + 慢边沿）**：**+0.7 dB**。
- 中间标称 **+15.9 dB**。
- **结论：DM 最差裕量 = +0.7 dB（悲观包络）**，跨度 **33.7 dB**，说明"寄生/走线不确定性"是本设计 DM 的第一大不确定源。

> 注：**纯理想（ESR/ESL 全为 0）反而给 +28.3 dB（比 v1 差）**。原因：10µF/ESL≈1.2nH 的 SRF≈1.6 MHz，在 805 kHz（低于 SRF）**ESL 使电容阻抗更接近 SRF 最小值**；把 ESL 归零会把 SRF 推高、805 kHz 处阻抗变大 ⇒ 基波 \|Zt\| 反而更大。**因此"去掉 ESL 就更乐观"是错的**——本报告用 v1 作为乐观参考而非"零寄生"。

### 3.3 主导寄生归因（满载，逐项单独放到悲观值，相对标称）

| 寄生（单独设悲观） | 最差裕量 | Δ vs 标称 |
|---|---|---|
| **热回路走线电感 L_hot** | 8.3 dB | **−7.6 dB** |
| **30µF 银行走线电感 L_tr_capA** | 8.7 dB | **−7.2 dB** |
| 10µF ESL | 14.6 dB | −1.3 dB |
| L1 支路走线电感 | 16.0 dB | +0.1 dB（可忽略）|
| F1/输入走线电感 | 15.9 dB | +0.0 dB（可忽略）|
| 电解 ESR | 15.9 dB | −0.0 dB |
| LISN 50→100 Ω | 15.9 dB | −0.0 dB |

**主导项 = 两段走线电感（源节点去耦路径 + 节点A 旁路路径）。** 这也解释了最差点从基波移到 4.03 MHz（5 次谐波）。

### 3.4 π 滤波价值（满载；图 `fig_emi_cispr_nofilter.png`）

| | \|Zt\|@805k | 基波 | 最差裕量 | @频率 |
|---|---|---|---|---|
| 有 π（3×10µF + L1） | 4.39 µΩ | 18.5 dBµV | **+15.9 dB** | 4.03 MHz |
| **无 π**（只剩本地电容旁路） | **33.1 mΩ** | **96.0 dBµV** | **−42.2 dB** | 4.03 MHz |

- 去掉 π 后 \|Zt\| 上升 **77.6 dB**，基波 DM 上升 **+77.5 dBµV**，最差裕量 → **−42.2 dB（严重超标）**。
- 物理解释：无 L1 时噪声电流直接面对本地电容（40µF，但其**热回路走线电感 L_hot=8nH 在 805 kHz 已是 ~40 mΩ，远大于电容 5 mΩ**），源节点电压被 L_hot 抬高，几乎全部经 50Ω LISN 被"看见"。π 滤波器用 L1 把源节点与 LISN 隔开（分压 ~Z_源/ Z_L1 ≈ 5mΩ/5Ω），提供约 58 dB 衰减。
- **副结论**：**热回路走线电感在"无 π"时是第一杀手**——即使有 π，它也是主导项。→ **减小 U21.VIN 热回路面积是 DM 的首选优化。**

### 3.5 敏感性扫描（图 `fig_sensitivity.png`，满载，Class B 最差裕量）

| 扫描量 | 裕量范围 | 备注 |
|---|---|---|
| 10µF ESL 0.3→3 nH | **11.2 → 18.0 dB** | 单调：ESL 越大，4 MHz 段 \|Zt\| 越差（负相关经分析确认见 §3.2 注）|
| L1 支路走线电感 0→60 nH | 16.3 → 15.8 dB | 几乎无影响（L1=1µH 主导）|
| **热回路走线电感 0→40 nH** | **37.4 → 2.5 dB** | **最强单变量** |
| **30µF 银行走线电感 0→15 nH** | **20.3 → 3.6 dB** | 第二强 |
| tr=tf 2→30 ns | 16.1 → 15.9 dB | **CISPR 频段内几乎无影响**（最差点在 4 MHz）|
| DM LISN 50 vs 100 Ω | 15.9 vs 15.9 dB | **Δ −0.00 dB** |

**LISN 50 vs 100Ω 为何几乎无差（重要物理解释）**：本拓扑下节点 A 被 30µF 银行并联到地（4 MHz 处 \|Z_cap\| 仅 ~1.3 mΩ，远小于 50/100Ω）。测量电压就是节点 A 的电压（≈电容的纹波电压），LISN 电阻被旁路，故加倍也不改变 V_A。**即 DM 发射实际由输入 X 电容的阻抗决定，而非 LISN 电阻。** 与"常见直觉（+6 dB）"不同，需注意这是本模型的**拓扑性结论**。

## 5. 局限（务必随结论一同引用）

1. **寄生为估值**：电容 ESR/ESL 与走线电感均为典型值/经验估算（1 nH/mm），未做实测或场提取（Q3D/2D 场求解）。**绝对值不可当真**，趋势与"主导项"可靠度较高。
2. **未含项**：① TVS D138 / 磁珠结电容等 HF 旁路；② 电容**直流偏压与温度降容**（X5R 10µF/50V 在 24V 偏压下有效容值可能降 30–60% ⇒ **实际会比本报告更差**）；③ 共模（CM）路径（v1 已指出 CM 可能是更大风险，本报告只做 DM）；④ 器件封装/引脚电感（0603/1206 本体 ESL 之外）。
3. **源为解析梯形波**：理想梯形波**占空比 0.5 时偶次谐波为零**，而实测非理想波形会填充这些零点（v1 观察到个别谐波 +150 dB 的填充）。故本报告**只比较奇次谐波与包络走势**，不评价单点偶次谐波；若加入真实波形/振铃，部分谐波可能更高。
4. **fsw=805 kHz 实测**，与 datasheet（RT=26.7k→784 kHz）偏差 +2.7%：谐波位置随之偏移，与标准频段边界比较时需注意。
5. **LISN 建模为单节点等效**，未展开完整两线网络；100Ω DM 为简化处理。
6. **仅在 150 kHz–30 MHz 频段评估**；未评估 30–108 MHz 辐射/近场。

## 6. 建议（工程）

1. **收紧 U21.VIN 热回路**（源↔本地电容↔GND）：目标把 L_hot 从估值 8 nH 降到 ≤3 nH（面积减半以上）→ 预计最差裕量 +8～12 dB。
2. **缩短节点 A 30µF 银行到 LISN/输入的走线**（L_tr_capA 3→1 nH）→ 再加数 dB。
3. **π 滤波不可删**（无 π 直接 −42 dB）；L1 与 3×10µF 是 DM 达标的必要条件。
4. **100nF C72 靠近 VIN 脚**，作为 HF 旁路抑制 4 MHz 以上相等等效串联电感带来的抬升。
5. **后续**：如需可信绝对值，应对输入电容 C17/C62/C63 做**实测 S 参数**，并对热回路做**场提取**（Q3D/2D）替代 1 nH/mm 估值；并加入 CM 与直流偏压降容。

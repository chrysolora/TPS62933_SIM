## 1. 做了什么

1. 读 `cm_pcb/cm_pcb_model.py`+`emi_cm/emi_cm_model.py`，复原 CM 电路与电流路径，判定是否经 LISN。

## 2. CM 模型物理正确性（最高优先）

### 2.1 电路（`cm_pcb_model.py` / `emi_cm_model.py` 实算回路）

```
    注入点  I_cm = 2πf·C_sw·V_sw
       │
  node0 = 板 GND (LISN 测量点)
    ├──────── R_lisn = 25 Ω ─────────────► 大地(-1)
    └── Z_cab = 0.05Ω + jω·30nH ─► node1(上游GND)
                                     └── Z_Cy=1/(jω·2.2nF) ─► 大地(-1)
  V_cm = |V[node0]|   （25Ω LISN 上的电压）
```

电流在 **node0（板 GND）注入**，返回端是**大地**；出口只有 `R_lisn(25Ω)` 与 `电缆→Cy(2.2nF)→大地` 两条。该模型**只有**在"注入电流确为离开板的 CM 电流"时才成立 → 耦合电容**必须**是"噪声节点 ↔ 大地"。

### 2.2 但 C_sw 取的是"SW ↔ 板下层 GND 平面"

- 静电场几何（`cm_pcb/case_mesh_*.sif`）：边界1 `SW`=1V；边界2 **板底地平面**(z=−1mm)=0V；边界3 **外部参考面**(z=−d)=0V。
- **Material 1 Relative Permittivity = 1.0** → 只按空气算，**FR4 未计入**；**无顶层共面 GND**。
- 报告自证（§3.2/§4.3）：C_sw 由**板上 1mm 间距主导**，外部参考面距离 d 影响 **<2%**。

### 2.3 判定：**这不是 CM 耦合电容**

- SW 铜皮与板下层 GND 平面是**同一块板上相邻两层**；其位移电流在板内闭合（经输入/输出电容、同步整流管、GND 平面镜像电流），**不需要**走电缆/LISN。
- 该回路就是**近场/DM 环流**（辐射模型该管的），**不是**传导 CM。真 CM 源应是 SW/开关噪声 ↔ **大地/机壳**（经 Y 电容/机壳/寄生）。`docs/07` 明文：**"C_p（板↔大地寄生）是闭合 CM 回路的唯一元件"**。cm_pcb 把 C_p **换成**了板内 C_sw → **元件取错**。
- **量化**（`cm_audit_probe.txt`，30MHz）：板内局域回流 |Z_loc|≈0.9~6 Ω，板↔大地(1.19pF)|Z|≈4458 Ω，电缆|Z|≈5.7 Ω → 局域回流阻抗低 ~3 个数量级，SW↔板GND 电流 **≈96%+ 就近闭合**，几乎不流向大地 → 当 CM 计入属**高估**。

### 2.4 换耦合元件后的裕量（`cm_audit_probe.txt`）

| 耦合电容定义 | 值 | 空载/半载/**满载** |
|---|---|---|
| C_sw 原模型（SW↔板GND,1mm） | 0.411 pF | +2.5 / −1.5 / **−0.3 dB** |
| 板↔大地（CISPR 10mm 面 ε0A/d） | 1.19 pF | −6.8 / −10.8 / **−9.5 dB** |
| 板↔大地（黑盒基线） | 10 pF | −25 / −29 / **−28 dB** |

→ 换用文档定义的"板↔大地"元件，满载裕量由 −0.3 dB 恶化到 **−9~−28 dB**。

## 3. 按用户层叠（2 层板, core 1.43mm）修正 C_sw

### 3.1 层叠与建模
- 用户给定：外铜 **0.030mm** / **core 1.43mm(FR4)** / 底铜 **0.030mm**，合计≈1.49mm（标称 1.6mm 含阻焊）。
- → 底层 GND 平面置于 **z=−1.43mm**（SW 顶面 ↔ 底铜顶面）；**FR4 填满该 1.43mm 空隙**。
- 顶层**共面 GND**（0V 电极，SW bbox 外 **0.3mm clearance**）同层建成。
- **εr 用 4.3 / 4.6 双档**；εr 以 z 坐标函数（MATC）施加，避免多材料几何切分伪影。
- **tanδ≈0.02 说明**：静电（准静态）问题只取实部 εr，tanδ 影响的是损耗（有耗介质的复介电虚部），**对 C 无贡献，可忽略**。

### 3.2 工具链验证
用本目录 `gen_geo4.py`+`make_sif4.py` **复现**原 1mm 空气几何：fullcu **C=0.41057 pF**（=原 `results.csv` 0.4107 pF，逐位一致）→ 工具链可信。

### 3.3 C_sw 修正结果（Elmer FEM，fullcu）

| 配置 | C_sw | 倍数(相对 1.43mm 空气) |
|---|---|---|
| 1.43mm **空气**（几何基线） | **0.3427 pF** | ×1 |
| + **FR4 εr=4.3**（无顶层GND） | **1.1099 pF** | ×3.24 |
| + **FR4 εr=4.6**（无顶层GND） | **1.1790 pF** | ×3.44 |
| + **顶层共面 GND**（空气） | **0.6895 pF** | ×2.01 |
| **+ FR4 εr=4.3 +顶层 GND（best）** | **2.4160 pF** | ×7.05 |
| **+ FR4 εr=4.6 +顶层 GND** | **2.5719 pF** | ×7.50 |

- 相对**原始 1mm 空气**的 0.4107 pF，修正后 **×5.88 (εr4.3) / ×6.26 (εr4.6)**。
- 分解：加厚(1→1.43mm) 使 C 降 ~×0.83；FR4 使升 ~×3.2；顶层共面 GND 使升 ~×2.0。

> **注意**：`cm_pcb` 中 topcut/dualcut 的 C_sw（0.3121/0.2021 pF）**无法用现工具链复现**：重跑 `cm_pcb/gen_geo.py topcut`（原脚本原几何）得 **1.44 pF**、网格仅 ~270 节点（退化）。dualcut 可复现(0.208 pF)、fullcu 可复现(0.4106 pF)。故下面三版对比中，topcut/dualcut 的修正值用**原模型的比例**外推（topcut 0.760、dualcut 0.492），并标注 **\***。

### 3.4 修正后 Full 满载 CM 裕量（`cm_corrected_margins.txt`）

## 4. 辐射 B2：收敛性对照（数值）

同源同条件（DM 激励、3.0A 满载、post_b2 归一化 Ipk=4.3A），只改网格：

| variant | L0 `--fast` 318k | L1 (1.0mm/18) 425k | L2 (0.75mm/14) 588k |
|---|---|---|---|
| **FullCopper** E@30M | **21.17** | **52.32** | **75.88** |
| **DualCutout** E@30M | **23.61** | **48.38** | **75.22** |
| **Dual − Full** | **+2.43 dB** | **−3.94 dB** | **−0.66 dB** |

- **单档加密自漂移**：Full L0→L2 = **+54.7 dB**、Dual = **+51.6 dB**（均单调发散：21→52→76 / 24→48→75）。
- **趋势**：+2.43 → **−3.94** → −0.66 dB（**符号翻转、无稳定值**）。
- 远场 E_norm 峰值频率 1000→641 MHz 漂移（谱形不稳定）。

### 4.1 直接证据：`--fast` 未收敛
`--fast`（40000 步，rad_b2 报数所用档）结束打印：
```
RunFDTD: Warning: Max. number of timesteps was reached before the end-criteria of -40dB was reached...
```
末态能量 **仅 −2.18 dB**（要求 −40 dB）——场仍满幅振荡。本目录复现档 `F0`（同参数 40000 步）同样停在 40000 步、能量 −2.18 dB。L1(120000 步)末态 −34.7 dB，仍未达 −40 dB。

**判定**：2.4~2.7 dB 的"挖铜变差"**远小于**网格收敛误差（25~55 dB），趋势符号随网格**翻转** → **不可分辨；方向结论不成立**。B2（`--fast`、幅值未标定）**未收敛**，绝对值与趋势均不可用。

## 5. 总结与建议

1. **CM 模型 `cm_pcb`：元件取错 + 漏项 → 结果不可信。**
   - C_sw = SW↔板下层 GND（板内电容），不经 LISN，属近场/DM，**非 CM**；真 CM 应为 **噪声源↔大地 C_p**（docs/07）。
   - 几何漏 **FR4** 与 **顶层共面 GND**；按用户层叠(2层,core 1.43mm,εr4.3/4.6)修正后 C_sw ≈ **0.41→2.42~2.57 pF**。
   - 修正后 **Full 满载 ≈ −16 dB，挖铜版 −13.3/−9.5 dB，全超**；**"挖铜转正"不成立**。
   - 附带：原 topcut 档 C_sw(0.3121 pF) **不可现工具链复现**（得 1.44 pF，网格退化）→ "挖铜"档数值本身存疑。

2. **辐射 B2：数值未收敛 → 趋势不可信**（漂移 25~55 dB，符号翻转）。

3. **"矛盾"根源**：两模型算的**不是同一物理机制**（板内 SW↔GND 近场/DM vs DM 辐射），叠加各自错误/未收敛，方向结论均**不可作设计依据**。

**建议**：
- CM：按 docs/07 用**板↔大地 C_p**（几何抽取或 2/10/50 pF）重跑；C_sw 若要保留须串联"板内局域回流分压"，或改用 SW↔大地的有效耦合；并把 **FR4(core 1.43mm) + 顶层共面 GND** 纳入。
- 辐射：跑到能量收敛（EndCriteria 1e-4，或 NrTS≫1e5），Full/Top/Dual 各取 ≥2~3 档网格；当前 `--fast` 结果应作废。

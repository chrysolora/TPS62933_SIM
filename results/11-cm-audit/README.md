# CM 模型审计 + 辐射收敛复核（用户质疑"电感下铺铜怎么反而超标"）

## 触发
用户问：传导 CM 说"挖铜变好"、辐射 B2 说"挖铜变差"——同一处铜方向相反，**计算有无错？**

## 结论 1：**CM 的耦合元件定义错了**（`cm_pcb`/`emi_cm`）
- `C_sw` 算的是 **SW ↔ 板下层 GND（板内）**，其位移电流回路**不经 LISN**（板内回流 |Z|≈1–6 Ω，vs 板↔大地 4458 Ω → **96%+ 就近闭合**）。
- 拿它当"共模耦合电容"属**概念性错误**：真 CM 应为"**噪声源 ↔ 大地/机壳**"耦合（见 `docs/07`）。
- 换用文档定义的 C_p：Full 满载 −0.3 → **−9.5 dB（几何）/ −28 dB（10pF）**。

## 结论 2：**按用户层叠修正后，CM 更差，不是变好**
层叠（用户提供）：2 层板，外铜 0.030 / **core 1.43 mm FR4** / 底铜 0.030。

| 配置（fullcu） | C_sw | 满载裕量 |
|---|---|---|
| 1.43mm 空气 | 0.343 pF | +1.3 |
| +FR4 4.3（无顶层GND） | 1.110 pF | −8.9 |
| +FR4 4.6（无顶层GND） | 1.179 pF | −9.4 |
| +顶层共面GND（空气） | 0.690 pF | −4.8 |
| **+FR4 4.3 +顶层GND** | **2.416 pF** | **−15.7** |
| **+FR4 4.6 +顶层GND** | **2.572 pF** | **−16.2** |

三版（εr4.3+顶层GND）：**fullcu −15.7 / topcut −13.3 / dualcut −9.5 dB → 全超，"挖铜转正"被推翻。**

## 结论 3：**辐射 B2 的"挖铜变差"不可分辨**（未收敛）
| 网格 | Full E@30M | Dual E@30M | Dual−Full |
|---|---|---|---|
| fast 318k | 21.17 | 23.61 | **+2.43** |
| 425k | 52.32 | 48.38 | **−3.94** |
| 588k | 75.88 | 75.22 | **−0.66** |

单档漂移 **+52~55 dB**；**Dual−Full 符号翻转**；`--fast` 末态能量 −2.18 dB（要求 −40 dB，openEMS 明确警告未收敛）。
→ **2.4 dB ≪ 收敛误差，版本差异不可分辨。** B2 绝对幅值与三版对比**均不可引用**。

## 结论 4：`cm_pcb` 的 topcut 值本身不可复现
重跑原脚本得 **1.44 pF**（原报 0.312 pF），网格退化到 ~270 节点；fullcu/dualcut 可复现。

## 局限
- topcut/dualcut 修正值为**比例外推**（标 `*`），其裁剪几何在现 gmsh 下网格退化；fullcu 为 FEM 实算。
- 顶层共面 GND 用 0.3mm clearance 矩形近似 → **偏乐观下界**（真实 pour 间隙更小则 C 更大、更差）。
- 辐射仅复核 DM（CM 比 DM 低 ~90 dB）。
- tanδ≈0.02 对静电 C 无影响。

## 净结论（不粉饰）
- **CM 绝对值不可信**（模型定义需重做：源↔大地通路）。
- **方向性上：按正确层叠修正后是"更差"** → 之前"临界/通过"偏乐观。
- **辐射三版差异 = 数值噪声**，不要引用"挖铜变差"。

# 15 · 传导共模 CM（**正确通路重做**）—— CM 确实超标 ~16 dB

> 取代 `results/07-conducted-cm/`（其耦合元件定义错误，见 `results/11-cm-audit/`）。

## 正确拓扑（旧的错在这）
```
SW dv/dt → C_p(板↔大地寄生) → 大地/参考地平面 → LISN(2×50Ω 并 = 25Ω CM) → 输入电缆 10cm → 回源
```
- 旧实现（07 / cm_pcb）把耦合定义成 **"SW↔板内 GND"** → 板内就近闭合 **96%+**、**不经 LISN** → **根本不是传导 CM**。
- 源：`results_v2/E_*.txt` 的 `v(sw)` 末段 32 整数周期 FFT（fsw=805kHz，谐波 1–37）；`I_cm=2πf·C_p·|V_sw|`，`V_cm=25Ω·I_cm`。

## C_p（真实几何抽取，含 FR4 core 1.43mm + 顶层共面 GND）
| 版本 | C_p | 备注 |
|---|---|---|
| FullCopper (εr4.3) | **2.416 pF** | **标称** |
| FullCopper (εr4.6) | 2.572 pF | |
| TopCutout | 1.836 pF | 比例外推 `*` |
| DualCutout | 1.189 pF | 比例外推 `*` |

## 结果：**三工况全部超 CISPR 32 Class B**（QP）
| 工况 | 最差 QP 裕量 | 频率 |
|---|---|---|
| 空载 | **−14.9 dB** | 2.415 MHz |
| 半载 * | −17.3 dB | 0.805 MHz |
| **满载** | **−16.0 dB** | 0.805 MHz |

- AV 限值再低 ~10 dB → 约 **−26 dB**（更差）。**满载仍超约 16 dB。**
- **敏感性**：C_p 1 pF → −8.3 dB；**2.416 pF → −16.0 dB**；10 pF → −28.3 dB。⇒ **即便 C_p 乐观取 1pF，仍超 8.3 dB**。

## 与旧 results/07 的差异
- 旧满载 **−28.3 dB** → 新 **−16.0 dB**，**改善 +12.3 dB = 20log10(10 / 2.416)** —— 差异**纯粹来自旧模型把 C_p 高估成黑盒 10 pF**。
- 旧"CM 比 DM 高 71 dB"同源于此错 ⇒ **不再引用该数字**。

## 结论
- **EMI 真瓶颈 = CM**（此结论现在建立在**正确通路**上，可引用）。
- **CM 超 Class B 约 16 dB**（最坏负载）；**π 滤波治不了 CM**；需 **Y 电容 / 共模扼流圈 / 减小 C_p（布局、屏蔽、缩短耦合）** 方向。

## 局限
half 的 SPICE **未稳态**（仅参考）；上游 LM50-20B24 的 65kHz CM 源**无权威谱、未建模**；C_p 为准静态抽取、topcut/dualcut 为比例外推；C_y=2.2nF 为估值（影响 ≤0.3 dB）；**未经实测验证**。

# 27 — 三版铺铜**几何核验**（真实挖铜 vs 假设矩形）

从 `epro/pourSim.epru` 逐版解析真源（`PCB8`=FullCopper / `PCB8_1`=TopCutout / `PCB8_2`=DualCutout）。三版**铺铜定义完全相同**，差异只在**新增禁布多边形 → 重铺扣铜**。

| 区域 | 假设矩形面积 | 真实多边形面积 | 假设高估 |
|---|---|---|---|
| A（L2 下） | 46.200 mm² | TopCut **30.446** / DualCut **34.635** | **+51.8% / +33.4%** |
| B（L1 下） | 19.860 mm² | TopCut **11.048** / DualCut **13.464** | **+79.7% / +47.4%** |

- **位置/包围盒：匹配**（中心偏移 ≤0.005mm，尺寸偏差 <0.01mm）。
- **形状：不匹配** —— 真实是**非凸"凹"多边形**（带 2 个焊盘缺口），**不是矩形**；TopCut 与 DualCut 的挖铜形状**本身也不同**。
- **面积：不匹配** —— 真实比假设**小 25–44%**（合计 TopCut 小 37% / DualCut 小 32%）。
- **判定：部分匹配**。**影响**：热模型按整矩形扣铜 = **多扣 1/3~1/2 的铜** → **夸大**"挖铜→扩热变差"（尤其 DualCut 的 L2 +13℃）。**→ 已按真实多边形重跑：`results/28-*`**。
- 局限[B]：未能用 `POURED` 重铺结果独立交叉验证面积（无层号、无显式外键，全板求和仅 22.5mm²，不足定论）。

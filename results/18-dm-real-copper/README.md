# 18 · 用「本板真实铜皮几何」重定 DM —— 结论：**DM 稳过 CISPR 32 Class B（QP+21…25 dB，AV+11…15 dB）**

> **回应**：16（dm-recheck）判"边缘"是因为用了**理论最坏布局**（热回路 20 nH）。
> 本板实际铜皮量出来 **≈2.7–4.4 nH**，**比模型的"标称 8 nH"还小** → 那个"悲观包络 20 nH = 真实值 7.4 倍"，正是**不属于本板的坏布局上界**。

## 真实铜皮（从 `pourSim.epru` 抽取）
| 铜 | 几何 | 说明 |
|---|---|---|
| **POUR1 24VIN（顶层）** | **3.0 × 9.3 mm，面积 27.8 mm²** | **宽铺铜**，不是细走线 |
| GND 顶层 POUR4 | 31.1 × 52.8 mm | 实心 |
| GND 底层 POUR6 | 30.0 × 54.9 mm | 实心（回流平面） |

热回路（VIN 脚 ↔ 本地电容）与 30µF 银行**同一块 24VIN 铺铜**，回流是 1.43 mm 下的 GND 平面。

## 两段电感（用真实尺寸算，非 1 nH/mm 拍脑袋）
真实 24VIN 段 l=9.3 mm、w=3.0 mm：
- **Grover 条带（无平面回流收益，偏上限）= 4.44 nH**
- **微带对平面（w=3, h=1.43, εr4.4）= 2.70 nH**
- ⇒ **热回路 L ≈ 2.7 – 4.4 nH**（模型标称 8 nH、悲观 20 nH）
- 30µF 银行段 ≈ **1.2 – 4.4 nH**（模型标称 3 nH ✓ 合理）

## 结果（CISPR 32 Class B，满载 Ipk=3A）
| 参数 | QP 裕量 | AV 裕量 |
|---|---|---|
| **真实铜皮 lhot=2.7nH** | **+25.1 dB** | **+15.1 dB** |
| 真实铜皮 lhot=3.6nH | +23.0 | +13.0 |
| 真实铜皮 lhot=4.4nH（保守 Grover） | +21.3 | +11.3 |
| [参考] 模型标称 8/3nH | +15.9 | +5.9 |
| [参考] 几何最坏 15/8nH | +3.5 | −6.5 |
| [参考] 模型悲观 20/8nH | +1.1 | −8.9 |

## 判定（可信度）
| 结论 | 等级 | 依据 |
|---|---|---|
| 本板两段铜皮电感 ≈2.7–4.4 nH（非 8/20nH） | **A−** | 从 epru **真实几何**抽尺寸，两个标准公式互为上下界 |
| **DM 稳过 Class B（QP+21、AV+11 以上）** | **B+** | 公式法定 L（非场提取）；源用解析梯形波（偶次谐波偏保守）|
| 16 的"边缘"仅由 20nH 坏布局造成 | **A−** | 20nH = 真实值 7.4 倍，见上表 |

## 诚实的边界（怎么做到 A）
- L 仍是**尺寸代入公式**，**未做 2D/3D 场提取**（真提取会更可信）。但即便取**保守的 Grover 4.4 nH**，QP/AV 仍 +21/+11 dB，**结论有 11 dB 以上余量，不是压线**。
- 源用解析梯形波；真实 SPICE 源在最差点(5次)反偏保守 ~2.8 dB（见 16 §4.2）。
- 仅 DM、仅 <30MHz；CM 见 17。

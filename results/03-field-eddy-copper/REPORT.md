# TPS62933 — L2 下铺铜涡流场仿真（真实铺铜几何，fea3）

日期：2026-09-24　目录：`/mnt/raid10/sim-work/tps62933/fea3/`

## 1. 目的
把上一轮（`fea2/`）「简化方铜片 20×20 mm、空气域 40×40×16 mm」的场仿真，
换成**从源工程重建的真实铺铜几何（贴合板框）**，重算 L2（电感）下方铜皮中的涡流 |J|，并出图。

## 2. 几何来源（数据驱动，非猜测）

源文件：`/mnt/raid10/sim-work/tps62933/epro/pourSim.epru`（立创 EDA Pro，含 SCH/BOARD/PCB）。
解析脚本：`parse_lib.py`（读取 DOCHEAD/PCB 行式记录）+ `gen_geo.py`（几何生成）。

- **板框**：PCB doc 中 `POLY layer=11`（板框层）：
  `R 0 30 1043.3071 1988.189 0 0`
  → 解释为「角点 + 宽 + 向下高」：`x∈[0, 1043.31] mil, y∈[-1958.19, 30] mil`
  = **26.50 mm × 50.50 mm**。该解释已用板上全部元件坐标交叉验证（元件 x∈[120,865]、y∈[-1860,-150] mil，全部落入该矩形）。
- **顶层铺铜**：解析全部顶层（layerId=1）`POUR` 轮廓（`R` 矩形与 `L/ARC` 多边形）：
  共 13 个（GND:POUR4、12V:POUR5、24VIN:POUR1、$1N22:POUR2、PPHV:POUR3、$1N17:POUR24、
  $1N6:POUR69、$1N7:POUR75、POUR51/52/73/74 等）。
  裁剪到板框后，**POUR4(GND) 覆盖整块板** → 顶层实际是一整块 GND 平面（其余为局部不同网络的铺铜）。
- **算法（保守做法，见 §5）**：
  `铜皮 = 板框 − ⋃(其余网络铺铜的轮廓)`（其余网络按各自的 bbox 矩形扣除，弧边用弦/包围盒近似）。
  结果：铜面积 = 板面积 × 81.2%（扣除 18.8% 的空洞），铜皮 = **贴板框的矩形 + 内部门洞**（见 `fig_field_top_v3.png`）。
- **POURED 填充多边形：未使用（无法可靠对齐）**。其全局包围盒
  `x∈[-1203, 333] mil, y∈[-198, 300] mil`，与 `POUR`/板框不在同一坐标系（负 x、超出板框），
  且 L2 邻域（`x≈245, y≈-660` mil）内**不存在任何填充多边形**。故按任务允许的保守做法：
  用 POUR 轮廓（而非 POURED 填充）。**影响见 §5。**

### 关键修正（务必记录）
任务交接单称「POUR24/POUR2/POUR3 覆盖 L2」——**经正确解析后不成立**。
正确的 `R` 语义为「角点 + 宽 + 向下高 + 旋转」，据此：
- POUR24 → `x[725,835] y[-1135,-880] mil`；POUR2 → `x[402,521] y[-1765,-1485]`；POUR3 → `x[589,707] y[-1765,-2230]`
- **三者都不含 L2(245,-660)**；真正覆盖 L2 的顶层铺铜只有 **POUR4(GND)**（整板 GND 平面）。
（交接单中该结论来自早期一次 `R` 解析错误，故弃用「3 个 POUR 并集」，改用「全部顶层 POUR ∩ 板框」。）

## 3. 仿真设置
- **坐标**：单位 m，原点平移到 L2 中心（L2 = 245,-660 mil → 平移后 (0,0)）。
- **铜**：35 µm 薄板（z∈[-35,0] µm），遵循 fea2 已验证的「薄板 + 面内加密」做法（不用 3D 实体四面体粗切）。
- **磁芯**：6.5×6.5×3.0 mm，z∈[0.2,3.2] mm，**µr = 40（估值，无 datasheet）**。
- **线圈**：闭合环 5.2×5.2×0.6 mm（挖去内芯），z∈[0.9,1.5] mm，
  `CoilSolver`（Stranded、闭合、法向 +z、Desired Coil Current = 6 A）。
- **空气域**：板框 bbox + 6 mm 边距，z∈[-8,12] mm；外边界 `AV=0`。
- **激励频率**：fsw = **784 kHz** → ω = 2π·784e3 = **4.92566e6 rad/s**（`case.sif`）。
- **加密**：L2 半径 ~10 mm 内 cl=0.3 mm；铜板面内 0.6 mm；磁芯 0.6 mm；空气 5 mm。
- **网格/求解**：Gmsh 4.12 + OCC（`BooleanFragments` 保共形）；ElmerGrid；Elmer 9.0
  `CoilSolver` + `WhitneyAVHarmonicSolver`(MUMPS 直接) + `MagnetoDynamicsCalcFields`。
  **26592 节点 / 159424 体单元**，求解耗时 ~200 s。

## 4. 结果（`case_t0001.vtu`）
铜板（顶层）涡流密度 |J| = √(Σ|J_re+iJ_im|²)：
- **峰值 |J| ≈ 2.90e7 A/m²**，位于距线圈轴 **r ≈ 4.7 mm** 处（`(-2.14, 4.15) mm`）。
- **径向分布（绕线圈环状、向外单调衰减）**：

  | r (mm) | 0–3 | 3–5 | 5–7 | 7–10 | 10–15 | 15–25 | 25–40 |
  |---|---|---|---|---|---|---|---|
  | mean \|J\| (A/m²) | 3.1e5 | 3.3e5 | 1.9e5 | 8.3e3 | 4.3e3 | 2.9e3 | 2.6e1 |

- **无大面积数值斑点**：|J| > 1e7 的节点仅占 **0.073%**（全部集中在线圈边缘）；> 5e6 仅 0.145%。
- 铜皮形状 = **真实铺铜轮廓（贴板框的矩形 + 内部门洞），非方块**（`fig_field_top_v3.png`）。

## 5. 假设与局限（务必阅读）
1. **µr = 40 为估值**（无 L2 数据手册）。µr 直接决定磁通与涡流幅度；µr 偏差会线性改变 |J| 量级，但**环状/衰减的定性形态不变**。
2. **POURED 填充不可用** → 用 `POUR` 轮廓近似铺铜：
   - 未扣除相邻网络间的**净空（clearance）**，铜**偏大**（低估涡流电阻，|J| 略偏高）；
   - 其余网络铺铜用 **bbox 矩形**近似（真实为带圆角/弧的多边形），门洞形状略失真。
3. **只建模顶层铜**（GND POUR4 + 局部铺铜）；**底层 GND(POUR6) 未建模**，过孔的 GND 缝合阵列未建模。
4. **铜厚按 1 oz = 35 µm**（源工程未显式给出）。
5. 铜用 **35 µm 薄板（准 2D）**：784 kHz 下铜的趋肤深度 δ≈94 µm > 35 µm，涡流仅部分发展；
   薄板网格（面内 0.6 mm / 板厚 35 µm，纵横比 ~17）可能对薄板内电流分布欠分辨。
6. 线圈为**理想股绕（stranded）**、单向 6 A，未含绕组交流电阻/邻近效应细节。
7. 仿真域约 38.5×62.5×20 mm，外边界 AV=0；对 784 kHz 的远场截断误差可忽略。

# comparison_table.md — TPS62933 CISPR 32 Class B 裕量对比（有π / 无π-a / 无π-b）

**判据**：裕量 = 限值 − 发射。**正=过**，**负=超**。每格标 A/B/C。

**π 段定义**：`L1(1µH) + PPHV_OUT_FILTER 电容组(C73‖C74=20µF + C72=100nF)`；
30µF 银行（PPHV 上、L1 前）不属 π 段，**三档全部保留**。

- 无π-a = 只短路 L1（两组电容全保留）
- 无π-b = 整个 π 段移除（L1 短路 + 去掉 C73/C74/C72）

口径与 `cispr_final/` 一致：L_hot=2.70 nH（真实铜皮）、C_p=2.416 pF（真实铜皮）、
源谱 results_v2/E_*.txt v(sw) 与解析梯形波(tr=tf=10ns)、CISPR 32 Class B QP+AV。

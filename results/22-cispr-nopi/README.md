# 22 — 无 π 型输入滤波器 对比（传导 CISPR, DM+CM）

**π 段定义** = `L1(1µH) + PPHV_OUT_FILTER 电容组(C73‖C74=20µF + C72=100nF)`；30µF 银行（L1 之前）不计入、三档保留。
**有 π 复现校验通过**：DM 满载 +25.1/+15.1、CM 满载 −16.0（与 results/20 逐位一致）。

**DM 裕量（正=过/负=超）**
| 工况 | 有π QP/AV | 无π-a(只短路L1) | 无π-b(整段移除) |
|---|---|---|---|
| 空载 | +48.6/+38.6 | +1.0/−9.0 | −1.8/−11.8 |
| 半载 | +31.2/+21.2 | −16.3/−26.3 | −19.1/−29.1 |
| 满载 | +25.1/+15.1 | **−22.3/−32.3** | **−25.1/−35.1** |

π 段增益（满载）≈ **+47.5 dB(a) / +50.3 dB(b)**。→ **没有 π，DM 满载超 ~22–25 dB。**
**CM 三档相同**（空载 −14.9 / 半载 −17.3 / 满载 −16.0）：本板 π 段全是**差模元件**（L1 串正线 + 电容到板内 GND），**CM 回路里没有 π 元件** → 与 π 无关（结构性结论）。
**口径敏感**：旧口径把 30µF 银行也算进 π（一并移除）→ 无π更差约 32dB（旧 −42.2dB），方向不变。
等级：DM/CM 裕量 **B**；L_hot/C_p **A**；π 增益相对差 **B+**。

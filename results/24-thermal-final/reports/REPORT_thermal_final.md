# TPS62933F 板级热仿真 — 最终版 (step-3)

目录: `/mnt/raid10/sim-work/tps62933/thermal_final/`  · 工具: gmsh 4.12 + Elmer 9.0 (稳态热)
三工况 (Iout = 3.0 / 1.5 / 0.6 A)、Tamb 25 / 40 °C、h 随 ΔT 自洽迭代 (E 级)。

> **一句话结论**: 满载 (3 A, 24→12 V) 总损 **3.02 W (η≈92.3%)**; 板均温 **73.2 °C**;
> **U21 结温 = 120 °C (最佳估计) / 139 °C (保守上界)** — **全部 < 150 °C, 通过 ≤150 °C 自洽性检查**。
> 前两版 300+ °C 是**模型错误**(残项凑损 + 读均匀化封装体局部峰), 已修正。

---

## 一、做了什么

1. **修正损耗预算 (A)**: 逐项按器件手册/算式计算, **取消 v2 的 2.48 W 残项**。总损 3.02 W (v1/v2 的 5 W 为高估)。DCR 逐项**核实到制造商数据手册**。
2. **芯片结温改为物理可信算法 (B)**: **不再读均匀化封装体的局部峰**(v1/v2 的致命错), 改用**解析节点法** `Tj = T_board@U21 + P_U21·θJB(19.3 °C/W, TI SLUSEA4D)`。为使 `T_board@U21` 网格无关, 对 U21 周围做**半径扫描**, 取收敛的 near-field 值 (r≥2.5 mm) 作基准, 并把**未收敛的原始 footprint 均温**列为**保守上界**。
3. **真实过孔 (C)**: 从 `epro/pourSim.epru` 抽 566 个真实过孔坐标 → `vias.json`; 算含过孔的层间等效导热 `k_z_eff`; 出"过孔 开/关"整板对比。
4. **终检门 (D)**: 网格收敛、ΣQ 守恒、≤150 °C 自洽性、场平滑 — 见第四节。

## 三、证据 (A/B/C/D 逐条)

### A. 损耗预算 (满载 3 A)

| 器件 | 算式 | 参数 | P | 来源级别 |
|---|---|---|---|---|
| D1 SS36 | `Vf·Iin` | 0.70 V × 1.70 A | **1.19 W** | D (SS36 手册) |
| L2 15 µH | `Iout²·DCR` | 3² × 0.085 Ω | **0.765 W** | **D (LCSC C41415624 手册 85 mΩ, 已核实)** |
| L1 1 µH | `Iin²·DCR` | 1.70² × 0.027 Ω | **0.078 W** | **D (LCSC C167203 手册 27 mΩ, 已核实)** |
| U21 导通 | `Iout²·(D·RdsHS+(1-D)·RdsLS)` | D=0.5, 76/32 mΩ | **0.486 W** | D (TI SLUSEA4D) |
| U21 开关 | `½·Vin·Iout·fsw·(tr+tf)` | 24V·3A·805kHz·10ns | **0.29 W 解析 / 0.50 W 名义** | **E** (tr=tf=5 ns TI 典型, 未实测; 名义含 Coss/栅驱) |
| **合计** | | | **3.02 W, η≈92.3%** | |

- **无任何残项**。U21 总功率 = 0.486 + 0.50 = **0.986 W** (v2 里是 2.97 W)。
- 开关项敏感性: tr=tf 5→10 ns, 0.29→0.58 W; 总损 2.81→3.22 W (η 92.8→92.0%)。
- **勘误**: `results/REPORT.md` 里 L2/L1 DCR 记为 50/35 mΩ(估计值), 与手册不符; 本报告以手册值 85/27 mΩ 为准。

### B. 芯片温度 (满载, 过孔 ON)

**算法 (i) 解析节点**: `Tj = T_board@U21 + P_U21 × θJB`,  θJB = **19.3 °C/W** (TI SLUSEA4D, D)。
`T_board@U21` 取 U21 周围**板顶面均温**(半径扫描, 见下):

| 参考半径 | L1 / L2 / L3 网格 (°C) | L2→L3 变化 | 说明 |
|---|---|---|---|
| r=1.0 mm (原始 footprint) | 110.4 / 114.9 / 120.5 | **+5.2%** | 未收敛 → **均匀化铜皮人为局部集中**(仅计上界) |
| r=2.5 mm | 98.9 / 100.1 / 100.9 | +0.8% | near-field 基准 |
| r=4.0 mm | 91.7 / 91.6 / 91.6 | **+0.02%** | 完全收敛 |

**U21 结温**:
- **最佳估计 Tj = 100.9 + 0.986×19.3 = 120.0 °C** (用收敛的 r=2.5 mm 基准)
- **保守上界 Tj = 120.1 + 19.0 = 139.2 °C** (用未收敛的原始 footprint 均温)
- 器件温度(满载): **D1 122.2 °C, L2 89.8 °C, L1 76.0 °C**, 板均温 **73.2 °C**

> 未用均匀化封装体的局部峰(其"die→board"读数仅 ½·θJB, 无法表示 die, v2 即栽在此); **1 W/θJB 标定**: 封装体 k=9.252 W/m·K 按 R = h/(k·A) 构造, 恰得 θJB = 19.3 °C/W, 与手册一致。

### C. 真实过孔 + 开/关对比 (整板档, L2 网格)

含 566 个真实过孔 (22/12 mil) 的层间等效导热: **k_z_eff = 1.361 W/m·K** (纯 FR4 0.313)。

| 量 | 过孔 ON (kz=1.361) | 过孔 OFF (kz=0.313) | 差 |
|---|---|---|---|
| 板均温 | 73.28 °C | 73.02 °C | −0.3 (整板几乎不变) |
| U21 焊盘底 T_board@U21 (r2.5) | 100.11 | 111.15 | **−11.0 °C** |
| **U21 Tj (最佳)** | **119.1** | **130.2** | **−11 °C** |
| D1 | 119.3 | 129.4 | −10.1 |
| L2 | 89.5 | 94.9 | −5.4 |

→ 过孔主要**局部**散热(pad 区), 对整板均温影响可忽略; 无过孔时 U21 结温升 ~11 °C。

## 五、假设 / GAPS / 可信度

**假设 (标注来源级别)**
- tr=tf=5 ns 未实测 → **E**; 开关损解析 0.29 W, 名义取 0.50 W (含 Coss/栅驱, E)。范围 0.29–0.70 W → 总损 2.81–3.22 W。
- θJB(U21)=19.3 °C/W 取 **TI SLUSEA4D** (D); 布局/铜面积与 JEDEC 测试板不同 → 真值可能有偏差。
- D1/L2/L1 的 θ 取经验值 30/15/20 °C/W (**E**, 无封装 θ 数据) → 仅影响器件体表温, 不影响 U21 结论。
- h 自然对流用 Churchill-Chu 平板关联式 (Lc 特征长), 随 ΔT 迭代收敛 (h≈11.8 W/m²K @ΔT≈50 K, **E**); ε=0.9 (**E**)。
- 过孔孔壁等效: 25 µm 镀铜, k_via=211 W/m·K (E); 改变镀层厚会小幅改 k_z_eff。
- 板有效散热含 3 处端子 (G=2.33 mW/K 各, E)。

**GAPS (未闭合)**
1. **开关损耗 tr/tf 未实测** → E, 已给敏感性 (贡献 ±0.2 W 总损, ±~4 °C Tj)。
2. **U21 footprint 原始局部峰网格未收敛 (L2→L3 5.2%)**: 系均匀化板未显式解析铜平面的横向扩热所致。**已改用收敛的 r≥2.5 mm near-field 基准 + 原始 footprint 作保守上界**, 不把未收敛值当结果。
3. **局部子模型 (方法 ii) 未完成**: `die→θjc→焊盘→顶层铜→过孔→底层铜` 子模型的 gmsh 几何 (die 与封装共面) 反复报 "overlapping facets", 时间盒内未攻克 → 用方法(i) 解析节点法(任务允许"二选一") + 半径收敛扫描互校替代。**残留 GAP**: 缺少独立于均匀化板的 die 局部分辨率验证。
4. **θJB 测试板差异**: 真值取决于实际焊接/铜面积。

**可信度等级**
- 板均温 73.2 °C、总损 3.02 W、ΣQ 守恒、η — **A** (输入已核、收敛/守恒通过)。
- U21 结温 **120 °C (最佳)** — **B**(依赖 θJB 与板侧基准定义; 定量可用但带假设) 。
- U21 结温 **139 °C (保守)** — **A**(作为上界; 网格未收敛侧不利, 真值 ≤ 此)。
- 开关损、器件 θ、h、ε — **E** (已给敏感性, 不影响主结论)。
- **无 C / X 级引用值**。

**投递判定: 模型通过自洽性检查, 结论可发布: U21 结温 < 150 °C。**

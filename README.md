### 最新结论（2026-09-24）

- **DM EMI（含寄生）**：v1 的 +34.4dB 是**假象**（缺走线电感）；v2 **标称 +15.9dB / 悲观 +0.7dB**（几乎贴 CISPR 32 Class B @4.03MHz）。**主导寄生 = 走线/回路电感**。**π 滤波挡掉 ~58dB**。CM 尚未正式建模（很可能是更大风险）。
- **场（真几何）**：板框 26.50×50.50mm，铜=板框−铺铜（占 81.2%）；|J|max≈2.9e7 A/m² @r≈4.7mm，径向单调衰减；>1e7 仅 0.073% 节点（无大面积斑点）。
- **三版涡流（fea4）**：电感下(r<3.25mm)均|J| FullCopper 5.3e5 → TopCutout **0** → DualCutout **0**；合并均|J| **−93% / −98%**。
  - 🔴 **2026-09-24 复核（`results/12-eddy-loss/`）**：fea4 的**损耗公式用错**（`∫σ|J|²` 应为 `∫ρ|J|²`）+ **B/J 不自洽** + **网格未收敛** → **fea4 绝对数不可引用**，|J| 图仅看形态。
- **三版辐射（rad / B2）**：曾报 E@3m TopCutout **+2.5dB**、DualCutout **+3.1dB**（挖铜恶化辐射）。
  - 🔴 **2026-09-24 复核（`results/11-cm-audit/`）**：网格加密后**单档漂移 +52~55 dB、Dual−Full 符号翻转**、openEMS **未收敛** → **三版辐射差异 = 数值噪声，不可分辨、不可引用**。
- ➡️ **总汇总（已过时，待重写）**：`docs/06-multi-variant-summary.md`　~~挖铜减损耗、但增辐射~~
- ✅ **2026-09-24 复核后的净结论**：**损耗侧**——电感下涡流损耗 ≪ DCR 铜损（**<0.1%**）→ **挖铜无温升收益**（上界式，较稳）；**EMI 侧**——辐射三版差异**不可分辨**、CM 绝对值**不可信且方向偏更超限** ⇒ **"挖铜到底好不好"，现有模型给不出可信答案**（见 `results/11`、`results/12`）。

## 一句话结论（TL;DR）

- **时域**：可用 ngspice 收敛，但**免费未加密模型有物理边界**（VIN 脚电容 >~30µF 不启动）→ 只能用缩版 π 滤波、跳过 14ms 软启动 ⇒ **结果定性可用、定量不可信**（详见 01）。
- **传导 EMI（DM）**：含已确认的真实 π 滤波时，DM **远低于 CISPR 32 Class B**；去掉 π 滤波则明显抬高。**但真正的瓶颈很可能是 CM（共模）**，本模型尚未覆盖。
- **场**：已打通「PCB → Gmsh → Elmer 3D 涡流 → ParaView 出图」链路；几何/磁芯参数为简化+估值，**用于趋势判断，不用于定量**。
- **三版铺铜（涡流+辐射）**：~~挖铜降涡流损耗、但恶化辐射~~ —— **该结论已于 2026-09-24 被复核推翻**：涡流损耗**本就 ≪DCR（<0.1%），挖铜无收益**；辐射三版差异**未收敛、不可分辨**。⇒ **现有模型无法判定"挖铜"利弊**（`results/11-cm-audit/`、`results/12-eddy-loss/`）。

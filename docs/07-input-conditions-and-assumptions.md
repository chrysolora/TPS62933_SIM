# 07 — 仿真前提与假设（重要，随结果一起更新）

> 本文件集中记录**输入条件 / 系统级前提**。凡与结果一起引用的前提，以本文件为准。

## 1. 电源链（系统级前提）★
```
[上游开关电源] ──(板外 10 cm 电线, 0.75 mm² 铜)── [本板 24VIN] ── ... ── [TPS62933F buck] ── [12V 输出]
```
- **上游噪声是真实存在的**：上游开关电源输出**纹波 ≈ 100 mV**（用户给定）→ **必须作为独立噪声源注入仿真**，不能只算本板开关动作。
- **板外走线**：**10 cm、0.75 mm² 铜电线**（用户指定）供电。
  - 截面 0.75 mm² → 等效直径 ≈ 0.98 mm（若为多股按等效截面）。
  - **电缆电感必须计入**（它是共模电流的通路 / 也是 DM 串联阻抗）。
- **待确认**：上游开关电源的**开关频率**（决定 100 mV 纹波的谱位置）。未给定前按典型值（如 65 k / 100 k / 500 kHz）做**敏感性**并标注。

## 3. 测试条件（辐射判读）
- **距离 3 m**、等级 **CISPR 32 Class B**、**无外壳/屏蔽**、**裸板 + 10 cm 输入电缆**。
- 开关边沿 **tr=tf=5 ns**（TI 典型值；有实测以实测为准）。
- 谐波：fsw=805 kHz，**D=0.5** → 偶次谐波深零点（用 ±2 谐波包络取值）。

## 4. 已知缺口（随版本收敛）
- **上游 100 mV 纹波源未纳入**（B1 版）→ B2 补入；**CM 主导辐射**尚未建模（很可能是瓶颈）。
- 器件寄生只在传导 EMI（emi v2/v3）里建；辐射版暂无。
- L1 自身涡流 / 激励（涡流版只激励 L2）→ 见 `results/04-cut-variants/README.md`，待 fea5。

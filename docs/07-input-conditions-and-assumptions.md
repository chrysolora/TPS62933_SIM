## D. CM 通路（由 A+C 推出）
回路只能这样闭合：
```
板 GND → 10cm 电缆 → 上游内部 Y 电容 → 上游金属机壳 → 主侧 PE/大地 →(空间寄生电容 C_p)→ 回板
```
- **C_p（板↔大地寄生电容）是闭合 CM 回路的唯一元件** → **必须显式建模 + 做敏感性（2 / 10 / 50 pF）**。
- 上游内部 **Y 电容**用假设值 + 敏感性（标注依据）。
- 标准 **CISPR 参考地平面保留**（测试布置），但**板本体不接 PE**（寄生耦合，非短接）。
- 报告须给 **有 PE vs 无 PE** 对比（若时间允许）。

## F. 测试/判读条件
- **距离 3 m**、等级 **CISPR 32 Class B**、**无外壳屏蔽**、**裸板 + 10 cm 双线输入**。
- 开关边沿 **tr=tf=5 ns**（TI 典型；有实测以实测为准）。
- 谐波：fsw 805 kHz、D=0.5 → 偶次谐波深零点（用 ±2 谐波包络取值）。

# 07 — 仿真前提与假设（重要，随结果一起更新）

> 本文件集中记录**输入条件 / 系统级前提**。凡与结果一起引用的前提，以本文件为准。

## 1. 电源链（系统级前提）★
```
[上游开关电源] ──(板外 10 cm 电线, 0.75 mm² 铜)── [本板 24VIN] ── ... ── [TPS62933F buck] ── [12V 输出]
```
- **上游噪声是真实存在的**：上游开关电源输出**纹波 ≈ 100 mV**（用户给定）→ **必须作为独立噪声源注入仿真**，不能只算本板开关动作。
- **板外走线**：**10 cm、0.75 mm² 铜电线**（用户指定）供电。
  - 截面 0.75 mm² → 等效直径 ≈ 0.98 mm（若为多股按等效截面）。
  - **电缆电感必须计入**（它是共模电流的通路 / 也是 DM 串联阻抗）。
- **上游电源已确认**（用户提供数据手册，2026-09-24）：

| 项 | 值 | 来源 |
|---|---|---|
| 型号 | 金升阳 **LM50-20Bxx**（对应 24V 档 = **LM50-20B24**） | 数据手册 2025.05.16 |
| **开关频率** | **65 kHz (typ)** | 手册「通用特性」 |
| 输出 | **24 V / 2.2 A**（52.8 W，效率 89%@230VAC） | 手册选型表 |
| **输出纹波噪声** | 24V 档 **≤150 mV**（20MHz 带宽，峰峰；用户实测口径 ≈100 mV） | 手册「输出特性」 |
| 安全等级 | **CLASS I**（金属外壳需接系统大地/PE） | 手册 |
| 隔离 | 输入-输出 **4000 VAC**、输出-PE 1250VAC | 手册 |
| EMC | 传导/辐射均 **CISPR32/EN55032 CLASS B** | 手册 |
| 尺寸 | 99×82×30 mm，自然空冷 | 手册 |

- **对本板的影响**：本板满载 12V/3A=36W → 输入 ≈1.67A@24V（< 2.2A 额定，余量足够）。
- **纹波谱位置**：上游 fsw=**65 kHz** → 30 MHz 对应第 **~461 次**谐波；能否辐射到 VHF 取决于上游开关边沿速率（手册未给 → 需假设，标注）。
- **CM 路径（重要更正，2026-09-24）**：上游为 CLASS I（主侧外壳接 PE），但**实测接线只有「+24V / GND」两根引出线接到测试板，板侧无 PE**（用户明确）。
  - ⇒ 不要给测试板加 PE 连线；**板上无低阻大地回流**。
  - CM 回路只能闭合为：`板 GND → 10cm 电缆 → 上游内部 Y 电容 → 上游机壳 → 主侧 PE/大地 →(空间寄生电容 C_p)→ 回板`。
  - **C_p 必须作为假设参数并做敏感性**（建议 2 / 10 / 50 pF），因为它是唯一把 CM 回路闭合的元件。
  - 标准 CISPR 参考地平面保持（测试布置），但**板本体不接 PE**。
- 仿真取**纹波幅值 150 mV**（手册 24V 档最坏值）+ **100 mV**（用户口径）双档对比。

## 3. 测试条件（辐射判读）
- **距离 3 m**、等级 **CISPR 32 Class B**、**无外壳/屏蔽**、**裸板 + 10 cm 输入电缆**。
- 开关边沿 **tr=tf=5 ns**（TI 典型值；有实测以实测为准）。
- 谐波：fsw=805 kHz，**D=0.5** → 偶次谐波深零点（用 ±2 谐波包络取值）。

## 4. 已知缺口（随版本收敛）
- **上游 100 mV 纹波源未纳入**（B1 版）→ B2 补入；**CM 主导辐射**尚未建模（很可能是瓶颈）。
- 器件寄生只在传导 EMI（emi v2/v3）里建；辐射版暂无。
- L1 自身涡流 / 激励（涡流版只激励 L2）→ 见 `results/04-cut-variants/README.md`，待 fea5。

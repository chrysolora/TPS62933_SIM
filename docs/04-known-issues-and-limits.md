# 04 · 已知问题与局限（务必先读）

本仓库的结果**都带明确的适用边界**。使用前请对照下表；**不要把近似结果当作设计依据**。

---

## A. 时域瞬态（`results/01-stage1-transient/`）

| # | 局限 | 影响 |
|---|---|---|
| A1 | 输入滤波用**缩版 π**（20µF–1µH–10µF），非真实 π（3×10µF–1µH–2×10µF+100nF） | 纹波/输入电流波形与真实不完全一致 |
| A2 | **跳过 14ms 软启动**（模型无 SS 脚） | 启动过程未仿真 |
| A3 | 瞬态**未真正稳态** + 能量不守恒 | **效率数值不可信** |
| A4 | 满载 Vout 偏低（11.29V）、Vpp 偏大（424mV） | 反映模型/收敛限制，非真实性能 |
| A5 | fsw 实测 805kHz 略高于设计 760–800kHz | 与 datasheet 公式 784kHz 有偏差 |

**定性结论可用**（能收敛、能看开关行为），**定量结论不可用**。

---

## B. 频域传导 EMI（`results/02-conducted-emi/`）

| # | 局限 | 影响 |
|---|---|---|
| B1 | **仅 DM（差分）**；CM（共模）只有**粗估** | **DM 不超标 ≠ EMC 达标**；CM 很可能是瓶颈 |
| B2 | 源为**解析梯形波**（非器件提取） | 谐波幅值/相位为近似 |
| B3 | 电容寄生、走线/回路电感**未建模**（理想电容） | **DM 结果偏乐观**，裕量应视为上限 |
| B4 | LISN 简化（DM 严格应两 50Ω 串联） | 差 ~6dB |
| B5 | **C1（12V 输出电容）值未知** | 不影响输入侧 DM，但**不得**用于输出纹波/环路 |
| B6 | TVS D138 结电容未建模；F1 按理想短路 | HF 段可能遗漏 |
| B7 | 软启动为**解析式，非仿真**；Iss=5.71µA 是 14ms 反推值 | 仅示意 |

> **CM 粗估**：Cp=5pF（**估值**）时，fsw 谐波处 ≈80dBµV，**超 Class B 约 20–45dB** ⇒ **CM 预期是约束瓶颈**。

---

## C. 电磁场 FEA（`results/03-field-eddy-copper/`）

| # | 局限 | 影响 |
|---|---|---|
| C1 | 几何**简化**：空气域 40×40×16mm、铜皮为 **20×20mm 方片**（非真实铺铜轮廓、非板框） | 画布≠板框；场分布为趋势 |
| C2 | 磁芯 **µr≈40 为估值**（无 datasheet）；磁芯损耗未建模 | 涡流幅值绝对值不可信 |
| C3 | 线圈激励电流 6.0A 为**估值** | 同上 |
| C4 | 铜厚 35µm 为**估值**（叠层未显式给出） | 涡流/损耗受影响 |
| C5 | 残留**少数单元局部奇点**（焊盘/角落） | 局部数值斑点 |
| C6 | 只做了单例（电感下铺铜），**未做三方案完整对比/参数扫描** | 尚不能定量比较"铺铜 vs 挖铜" |

**趋势可用**（涡流呈绕线圈环状、向外衰减、峰值在电感半径处），**定量不保证**。

---

## D. 通用红线

- 所有**未从权威来源确认**的参数（磁芯 µr、铜厚、寄生、源边沿、激励电流、Cp）均为**估值**，已在各文档标注"依据 + 影响"。
- **SPICE 不含铜皮** ⇒ 三铺铜方案的电路层结果相同，差异只在场仿真层。
- 缺关键参数时**停止上报**，不臆造。

## 2026-09-24 新增（复核发现，重要）

- **fea4 涡流损耗公式用错**：用了 `∫σ|J|²`，正确应为 `∫ρ|J|²`（ρ=1/σ）→ 差 σ²≈3.4×10¹⁵ 倍。
- **fea4/fea5 B/J 不自洽**：`WhitneyAVHarmonicSolver`+CoilSolver 铜层 |B|≈4.6mT 却 J 小 1–2 个量级 → 绝对损耗不可用。
- **fea4 损耗数据自相矛盾**：topcut 底层铜完整却比 fullcu 低 154×，dualcut 反高 15× → 物理不可能。
- **fea4 网格未收敛**（0.4→0.2mm 残差仍 0.06）→ 无法给 <10% 收敛证据。
- **cm_pcb（10）CM 元件定义错**：`C_sw`=SW↔板内 GND，回路**不经 LISN**（板内回流 1–6Ω vs 板↔大地 4458Ω → 96%+就近闭合）→ 当 CM 属概念错误；真 CM 应"源↔大地/机壳"。且 topcut 的 0.312pF **不可复现**（重跑 1.44pF）。
- **B2/rad 辐射未收敛**：网格三档 E@30M 21.17→52.32→75.88（漂移 +54.7dB），Dual−Full 符号翻转 → 三版差异不可分辨。
- ⇒ 结论：**fea2/fea4/10/B2 的绝对数与三版相对差异均不可引用**；仅 |J| 形态、机理方向可用。

## 阶段 0 · 环境与资料

1. 选定计算主机 `node249`（Ubuntu 24.04，12 核/15G，RAID10 数据盘）——磁盘大户走 `/mnt/raid10`。
2. 装工具链：ngspice 42、Elmer FEM 9.0、Gmsh 4.12、ParaView 5.11、Python 科学栈。

4. **从原理图逐脚核对拓扑**，据此整理 `docs/03-input-filter-topology.md` 与器件型号表。

## 阶段 1 · 电路时域（ngspice）

1. **首版网表不收敛**：`Timestep too small ... trouble with node "x1.x_u5_u8.inm1"`（模型内部积分器节点），`run simulation(s) aborted`。启动瞬态对收敛极敏感。
2. **多轮 solver 调参**：扫描 reltol/abstol/gmin/trtol/maxstep/uic/seed/gear 等，最终收敛参数见 `01-simulation-method.md` §2。
3. **发现模型物理边界**（本轮最大收获）：
   - **VIN 脚电容 >~30µF ⇒ 模型不启动**（内部使能/UVLO 不置位）。⇒ 真实 π（>40µF）根本跑不了，只能缩版。
   - 模型 **EN 脚灌 0.2–2.3mA**，板上 R87/R88 分压使 EN≈0.27V → 不使能（需外部处理）。
   - 可用模型是 **P 版（无 SS 脚）** ⇒ **14ms 软启动无法仿真**。
4. **收敛达成**（rc=0，三工况，无 aborted），但：
   - fsw≈805kHz（略高于 760–800）；Vout 满载 11.29V；Vpp 满载 424mV；**效率不可信**（未稳态 + 能量不守恒）。
5. **交付定性为「工程近似」**（缩 π + 跳软启动），并写**近似声明**。见 `results/01-stage1-transient/README.md`。

## 阶段 2 · 电磁场 FEA（电感下铺铜涡流）

1. 从 epru 提取 L2 几何/叠层（2 层板、FR4 1.51mm、铜厚未给→按 35µm 估）。
2. **第一版翻车（重大教训）**：把 **35µm 铜皮当 3D 实体切四面体** → 网格畸变、数值斑点噪声，图无效。
   - **修正**：铜改用 **2D 壳单元**；电感附近半径 ~10mm 内加密（cl≈0.3mm）；出图前 `CellDataToPointData`。
3. 修好后通过验收：网格 58177 cell / 8217 node，Elmer exit 0；|J| 峰值半径≈电感半径；局部残差 std≈0.006。
4. 修正频率：早期误用 497kHz → 改为 **784kHz**。
5. 残留：少数单元局部奇点（焊盘/角落），后续清理。

### 用户质疑（重要反馈）
> "fea2 画布为什么不是我板框大小？显示的是什么？EMI？热量？"
> **答复**：fea2 是**围绕 L2 的局部模型**（空气域 40×40×16mm，铜皮被简化成 20×20mm 方片），画布=仿真域≠板框；
> 图上画的是 **|J| 感应涡流电流密度（A/m²）**，**不是 EMI 辐射、也不是温度**（热量=joule heating=|J|²/σ，另算）。
> **改进**：用真实 `POUR/POURED` 铺铜轮廓重建铜皮并裁到板框（fea3，进行中）。

## 阶段 3 · 频域传导 EMI（CISPR 近似）

1. 先确认源频率：从 `results_v2/E_*.txt` 数据得 **fsw = 805.0 kHz**。
2. 因瞬态未真正稳态（Vout 漂移、占空比不物理）⇒ 源改用**解析梯形波**，数据 FFT 作交叉校验。
3. 按已确认 π 拓扑建 2 节点线性网络 + LISN，算 `|Zt|`。
4. 结果：**DM 全过 Class B**（最差裕量 +34.4dB）。
5. **自我质疑 + 复核**：用户问"怎么算的？为什么这么低？"
   - 手算复核 `|Zt|@805kHz≈6.3µΩ` → **自洽**（源在 VIN 节点被本地电容旁路，穿 L1 的电流仅 ~0.2%，到 LISN 口又被 30µF 近乎短路）。
   - **结论**：不是 bug，是**理想电容模型**的预期；偏乐观原因 = 未含 ESR/ESL/走线电感、源 tr/tf 为估值、LISN 简化。
   - ⇒ 已启动 **DM-v2**（含寄生 + 真实源 + 敏感性扫描），并追加 **"无 π 滤波"对比图**。
